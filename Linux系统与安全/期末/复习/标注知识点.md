第一章 Linux 安全基础

1\. 操作系统安全 7 大目标

防非法访问、身份鉴别、运行监督、系统完整、访问控制、可追责、连续保护。

口诀：识（身份）访（访问）监（监督）完（完整）追（追责）续（连续）

2\. 9 类系统漏洞

输入验证、缓冲区溢出、边界条件、竞争条件、访问校验、意外逻辑、配置错误、环境变量、顺序化漏洞。

口诀：输缓边竞访，意配环顺

3\. 关闭 30+ 无用服务（考试写 6 个即可）

bluetooth、cpuspeed、firstboot、gpm、ip6tables、nfs

systemctl stop 服务名 && systemctl disable 服务名

4\. 禁止 Ctrl+Alt+Del

systemctl mask ctrl-alt-del.target

5\. 不升级内核只升软件包

yum \--exclude=kernel\* update

6\. /tmp 防木马三件套

noexec、nosuid、nodev → 挂载选项直接背"三 no"

第四章 用户·组·密码

1\. 四核心文件

/etc/passwd 用户信息

/etc/shadow 密文与策略

/etc/group 组信息

/etc/login.defs 长度/过期策略

2\. 用户管理 3 件套

useradd -m -s /bin/bash u1 // -m 建家目录

passwd u1 // 交互设密

userdel -r u1 // -r 连带家目录

3\. 组管理 3 件套

groupadd g1

gpasswd -a u1 g1 // 把用户加入组

groupdel g1 // 删空组

4\. 密码安全 6 要点

定期换、不含单词生日、长度≥8、大小写数字符号混用、不同系统不同密、不手写

5\. su vs sudo

su - // 切 root 需 root 密

sudo cmd // 用本人密，受 /etc/sudoers 限制

第五章 文件系统安全

1\. 三种权限 rwx 421

r=4 w=2 x=1 口诀：读 4 写 2 执行 1

2\. 三类人 ugo

u 主人 g 同组 o 其他

3\. 权限字符串→八进制

rwxr-xr-x → 111 101 101 → 7 5 5

4\. umask 计算

root 022 → 文件 644 目录 755

普通 002 → 文件 664 目录 775

公式：默认目录=777-umask；文件再减 111

5\. chmod 速记

字符：chmod u+x,go-w file

数字：chmod 755 file

6\. chown/chgrp

chown owner:group file

-R 递归

7\. 特殊位

suid=4 sgid=2 sticky=1

chmod 4755 file // 出现 rws

8\. 查找特殊位

find / -perm /4000 // suid

find / -perm /1000 // sticky

9\. 挂载三原则

mount → 使用 → umount

Busy 时 fuser -k 挂载点

10\. df/du 分工

df 看 FS 剩余 du 看目录大小

-h 人类可读
