1.1 Web开发简史

从静态页面到现代Web应用的演进之路

核心知识点

  • 静态网页时代 - 纯粹的HTML/CSS页面，无交互性
  • 动态网页革命 - PHP/ASP/JSP等技术实现服务器端渲染
  • Ajax的诞生 - 实现异步数据加载，提升用户体验
  • 前端框架崛起 - Angular, React, Vue三足鼎立
  • 现代Web应用 - SPA（单页应用）成为主流

技术演进示例

<!-- 1995: 静态HTML -->
<h1>欢迎访问</h1>
<p>这是一个静态页面</p>

<!-- 2005: PHP动态页面 -->
<?php echo "<h1>欢迎, " . $_SESSION['username'] . "!</h1>"; ?>

<!-- 2023: Vue组件 -->
<template>
  <h1>欢迎, {{ username }}!</h1>
</template>

1.3 Vue和MVVM模式

理解Vue的响应式核心原理

MVVM模式解析

  • Model - 数据层（JavaScript对象）
  • View - 视图层（DOM）
  • ViewModel - Vue实例，连接Model和View
  • 双向数据绑定 - 数据变化自动更新视图，视图变化自动更新数据
  • 声明式编程 - 关注"做什么"而不是"怎么做"

Vue MVVM示例

<!-- View -->
<div id="app">
  <p>{{ message }}</p>
  <input v-model="message">
</div>

<!-- ViewModel -->
<script>
  const app = new Vue({
    el: '#app',
    data: { // Model
      message: 'Hello Vue!'
    }
  });
</script>

为什么选择Vue.js？

Vue以其简洁的API、渐进式框架和出色的性能，成为当今最受欢迎的前端框架之一。

学习Vue将为您打开现代Web开发的大门，让您能够构建复杂的单页应用和用户界面。

1.4 Vue.js开发中常用的工具

提升开发效率的利器

核心工具集

  • Vue CLI - 官方脚手架工具，快速搭建项目
  • Vue Devtools - 浏览器调试工具
  • Vue Router - 官方路由管理
  • Vuex - 状态管理模式
  • Vite - 新一代前端构建工具
  • Pinia - Vue新一代状态管理库

使用Vue CLI创建项目

# 安装Vue CLI
npm install -g @vue/cli

# 创建新项目
vue create my-project

# 进入项目目录并运行
cd my-project
npm run serve

几秒钟后，您的第一个Vue应用将在 http://localhost:8080 运行！
