Vue实例

什么是Vue实例？

Vue.js遵循MVVM模式，其核心是创建一个"视图模型"(ViewModel)对象，作为"视图"(View)和"业务模型"(Model)之间的桥梁。

记忆提示： MVVM模式可理解为：Model（数据） ↔ ViewModel（Vue实例） ↔ View（界面）

  • Vue.js提供一个Vue类型，开发者通过创建Vue实例实现视图模型定义
  • 一个应用通常有一个唯一的根实例
  • 实例语法：const vm = new Vue({ /* 选项对象 */ })

创建Vue实例

创建Vue实例需要传入一个选项对象，该对象指定实例的行为和与页面的交互方式。

Vue实例基本结构
<!-- HTML -->
<div id="app">
  <h1>{{ message }}</h1>
</div>

<script>
// 创建Vue实例
const app = new Vue({
  // 挂载点
  el: '#app',
  // 数据对象
  data: {
    message: 'Hello Vue.js!'
  }
});
</script>
运行结果

{{ message }}

重要概念：根实例

在一个完整的项目中，可能会创建多个Vue实例形成层次结构，但通常应用会有一个唯一的最上层Vue实例，称为"根实例"。

容器和实例是一一对应的关系，真实开发中通常只有一个Vue根实例，配合组件一起使用。

模板语法

Vue模板语法分类

Vue提供两种主要的模板语法：插值语法和指令语法

  • 插值语法 - 用于解析标签体内容，使用双大括号：{{ expression }}
  • 指令语法 - 用于解析标签（属性、内容、事件等），以v-开头

1. 插值语法

插值语法使用双大括号{{ }}，内部可以写JavaScript表达式。

插值语法示例
<div id="interpolation-example">
  <h2>{{ title }}</h2>
  <p>计算结果: {{ 5 + 3 }}</p>
  <p>三元表达式: {{ isMember ? '会员' : '非会员' }}</p>
  <p>函数调用: {{ formatDate(new Date()) }}</p>
</div>

<script>
new Vue({
  el: '#interpolation-example',
  data: {
    title: '插值语法演示',
    isMember: true
  },
  methods: {
    formatDate(date) {
      return date.toLocaleDateString();
    }
  }
});
</script>
运行结果

{{ title }}

计算结果: {{ 5 + 3 }}

三元表达式: {{ isMember ? '会员' : '非会员' }}

函数调用: {{ formatDate(new Date()) }}

2. 指令语法

指令语法用于操作DOM元素，所有指令以v-开头。常见指令包括：v-bind、v-model、v-for、v-if等。

指令语法示例
<div id="directive-example">
  <!-- v-bind绑定属性 -->
  <a v-bind:href="url">访问{{ siteName }}</a>
  
  <!-- v-bind简写 -->
  <a :href="url">简写形式访问{{ siteName }}</a>
  
  <!-- v-on绑定事件 -->
  <button v-on:click="counter++">增加计数</button>
  
  <!-- v-on简写 -->
  <button @click="counter = 0">重置计数</button>
  
  <p>计数: {{ counter }}</p>
</div>

<script>
new Vue({
  el: '#directive-example',
  data: {
    url: 'https://vuejs.org',
    siteName: 'Vue官网',
    counter: 0
  }
});
</script>
运行结果
访问{{ siteName }}

简写形式访问{{ siteName }}

计数: {{ counter }}

JS表达式 vs JS语句

在插值语法{{}}中只能写JS表达式，不能写JS语句：

  • 表达式：产生一个值，如 a, a+b, demo(), x === y ? 'a' : 'b'
  • 语句：控制程序流程，如 if() {}, for() {}

数据绑定

数据绑定类型

Vue中有两种主要的数据绑定方式：单向绑定和双向绑定

  • 单向绑定 (v-bind) - 数据只能从data流向页面
  • 双向绑定 (v-model) - 数据能从data流向页面，也能从页面流向data

1. 单向数据绑定

使用v-bind指令实现单向数据绑定，数据变化会自动更新视图，但视图变化不会影响数据。

单向绑定示例
<div id="one-way-binding">
  <input type="text" v-bind:value="message">
  <p>输入框内容: {{ message }}</p>
  <button @click="message = 'Hello Vue!'">更改数据</button>
</div>

<script>
new Vue({
  el: '#one-way-binding',
  data: {
    message: '初始值'
  }
});
</script>
运行结果

输入框内容: {{ message }}

2. 双向数据绑定

使用v-model指令实现双向数据绑定，主要用于表单元素，实现视图和数据同步。

双向绑定示例
<div id="two-way-binding">
  <input type="text" v-model="message">
  <p>输入框内容: {{ message }}</p>
  
  <h4>选择你喜欢的框架:</h4>
  <select v-model="selected">
    <option disabled value="">请选择</option>
    <option>Vue</option>
    <option>React</option>
    <option>Angular</option>
  </select>
  <p>你选择了: {{ selected }}</p>
</div>

<script>
new Vue({
  el: '#two-way-binding',
  data: {
    message: '初始值',
    selected: ''
  }
});
</script>
运行结果

输入框内容: {{ message }}

选择你喜欢的框架:

你选择了: {{ selected }}

特性 v-bind (单向) v-model (双向)
数据流向 data → 视图 data ↔ 视图
适用场景 普通HTML属性绑定 表单元素(input, select等)
简写形式 :attribute 无简写
数据更新 数据变化更新视图 数据视图相互更新

内置指令

Vue常用内置指令

Vue提供多种内置指令，用于处理DOM操作和数据渲染：

  • v-text - 更新元素的文本内容
  • v-html - 更新元素的innerHTML
  • v-pre - 跳过该元素和其子元素的编译
  • v-cloak - 防止未编译的Mustache标签显示

1. v-text 和 v-html

v-text用于设置元素的文本内容，v-html用于设置元素的HTML内容。

v-text和v-html示例
<div id="text-html-example">
  <!-- v-text 示例 -->
  <div v-text="textContent"></div>
  
  <!-- v-html 示例 -->
  <div v-html="htmlContent"></div>
  
  <!-- 插值语法对比 -->
  <div>{{ htmlContent }}</div>
</div>

<script>
new Vue({
  el: '#text-html-example',
  data: {
    textContent: '这是普通文本内容',
    htmlContent: '<strong>这是HTML内容</strong> <em>带有格式</em>'
  }
});
</script>
运行结果
{{ htmlContent }}

v-html的安全警告

使用v-html指令时需要注意：

  • v-html会直接渲染HTML内容，可能导致XSS攻击
  • 仅对可信内容使用v-html，永远不要用于用户提交的内容
  • 在服务端对用户提交内容进行过滤和转义

2. v-pre 和 v-cloak

v-pre用于跳过编译过程，v-cloak用于防止未编译的模板闪现。

v-pre和v-cloak示例
<style>
  [v-cloak] { display: none; }
</style>

<div id="pre-cloak-example">
  <!-- v-pre 示例 -->
  <div v-pre>{{ 这里的内容不会被编译 }}</div>
  
  <!-- v-cloak 示例 -->
  <div v-cloak>
    加载完成后才会显示: {{ message }}
  </div>
</div>

<script>
// 模拟延迟加载
setTimeout(() => {
  new Vue({
    el: '#pre-cloak-example',
    data: {
      message: 'Vue已加载完成!'
    }
  });
}, 2000);
</script>
运行结果
{{ 这里的内容不会被编译 }}
加载完成后才会显示: {{ message }}

注意：这里模拟了2秒延迟加载，实际中v-cloak用于解决网速慢时显示{{}}的问题

Vue实例生命周期

什么是生命周期？

Vue实例从创建到销毁的整个过程称为生命周期。在这个过程中，Vue会在不同阶段调用特定的"生命周期钩子"函数。

记忆提示： 生命周期钩子函数名称不可更改，但函数内容可根据需求编写

生命周期函数中的this指向的是Vue实例对象

生命周期图示

beforeCreate
实例刚被创建，data和methods还未初始化
created
实例创建完成，data和methods已初始化
beforeMount
模板编译完成，但尚未挂载到页面
mounted
实例已挂载到页面，DOM操作可在此进行
beforeUpdate
数据更新前调用，此时数据已更新但视图未更新
updated
数据更新完成，视图已重新渲染
beforeDestroy
实例销毁前调用，此时实例仍可用
destroyed
实例销毁完成，所有绑定和监听被移除
生命周期钩子示例
<div id="lifecycle-example">
  <h3>{{ message }}</h3>
  <button @click="message = '更新后的消息'">更新数据</button>
  <button @click="$destroy()">销毁实例</button>
  <div id="log"></div>
</div>

<script>
new Vue({
  el: '#lifecycle-example',
  data: {
    message: '初始消息'
  },
  beforeCreate() {
    this.log('beforeCreate: 实例刚被创建');
  },
  created() {
    this.log('created: 实例创建完成');
  },
  beforeMount() {
    this.log('beforeMount: 模板编译完成，即将挂载');
  },
  mounted() {
    this.log('mounted: 实例已挂载到页面');
  },
  beforeUpdate() {
    this.log('beforeUpdate: 数据即将更新');
  },
  updated() {
    this.log('updated: 数据更新完成');
  },
  beforeDestroy() {
    this.log('beforeDestroy: 实例即将销毁');
  },
  destroyed() {
    this.log('destroyed: 实例已销毁');
  },
  methods: {
    log(text) {
      const logElement = document.getElementById('log');
      const p = document.createElement('p');
      p.textContent = text;
      logElement.appendChild(p);
    }
  }
});
</script>
运行结果

{{ message }}

常用生命周期钩子

在实际开发中，最常用的生命周期钩子：

  • created - 用于初始化数据，发送AJAX请求
  • mounted - 用于操作DOM，初始化第三方库
  • beforeDestroy - 用于清除定时器、取消事件监听
