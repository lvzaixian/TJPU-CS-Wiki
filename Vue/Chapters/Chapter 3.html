Vue计算属性与侦听器

计算属性(computed)和侦听器(watch)是Vue.js中处理数据变化的两种核心机制，它们使开发者能够优雅地响应数据变化并执行相关操作。

为什么需要计算属性和侦听器？

在Vue应用中，我们经常需要：

  • 根据现有数据派生新数据（如全名 = 姓 + 名）
  • 在数据变化时执行异步操作（如API调用）
  • 对数据变化进行更复杂的响应（如验证、日志记录）

计算属性用于同步计算派生值，而侦听器用于响应数据变化执行操作。

计算属性

什么是计算属性？

计算属性是Vue中用于声明式地定义派生值的方式。它们基于响应式依赖进行缓存，只在相关依赖发生改变时才会重新计算。

JavaScript基础： 计算属性本质上是使用Object.defineProperty()方法定义的getter函数，这使得Vue能够追踪依赖并在依赖变化时自动更新。

1. 计算属性的基本用法

下面是一个使用计算属性拼接全名的简单示例：

计算属性基本用法
<div id="computed-basic">
  <div class="input-group">
    姓: <input type="text" v-model="firstName">
  </div>
  <div class="input-group">
    名: <input type="text" v-model="lastName">
  </div>
  <h3>全名: {{ fullName }}</h3>
</div>

<script>
Vue.createApp({
  data() {
    return {
      firstName: '张',
      lastName: '三'
    }
  },
  computed: {
    // 计算属性 - 全名
    fullName() {
      console.log('计算属性重新计算');
      return this.firstName + '-' + this.lastName;
    }
  }
}).mount('#computed-basic');
</script>
运行结果
姓:
名:

全名: {{ fullName }}

计算属性 vs 方法

虽然使用方法也可以实现类似功能，但计算属性具有重要优势：

  • 缓存机制 - 计算属性基于响应式依赖进行缓存，只有当依赖变化时才会重新计算
  • 高效性 - 避免不必要的重复计算
  • 声明式语法 - 在模板中像普通属性一样使用

当需要多次访问派生值时，计算属性是更好的选择。

2. 计算属性的setter

计算属性默认只有getter，但也可以提供setter：

计算属性的setter
<div id="computed-setter">
  <div class="input-group">
    姓: <input type="text" v-model="firstName">
  </div>
  <div class="input-group">
    名: <input type="text" v-model="lastName">
  </div>
  <div class="input-group">
    全名: <input type="text" v-model="fullName">
  </div>
</div>

<script>
Vue.createApp({
  data() {
    return {
      firstName: '张',
      lastName: '三'
    }
  },
  computed: {
    // 带setter的计算属性
    fullName: {
      // getter
      get() {
        return this.firstName + '-' + this.lastName;
      },
      // setter
      set(newValue) {
        const names = newValue.split('-');
        this.firstName = names[0] || '';
        this.lastName = names[1] || '';
      }
    }
  }
}).mount('#computed-setter');
</script>
运行结果
姓:
名:
全名:
关键记忆点： 计算属性适用于同步计算派生值的场景。当需要处理异步操作或执行副作用时，应使用侦听器。

侦听器

什么是侦听器？

侦听器用于观察和响应数据的变化。当需要在数据变化时执行异步操作或复杂逻辑时，侦听器非常有用。

JavaScript基础： 侦听器使用Vue的watch选项定义，可以观察数据属性、计算属性或嵌套对象的变化。

1. 基本侦听器

下面是一个监听天气变化的简单示例：

基本侦听器
<div id="watch-basic">
  <h3>今天天气很{{ info }}</h3>
  <button @click="changeWeather">切换天气</button>
</div>

<script>
Vue.createApp({
  data() {
    return {
      isHot: true
    }
  },
  computed: {
    info() {
      return this.isHot ? '炎热' : '凉爽';
    }
  },
  methods: {
    changeWeather() {
      this.isHot = !this.isHot;
    }
  },
  watch: {
    // 侦听isHot的变化
    isHot(newValue, oldValue) {
      console.log(`天气从${oldValue ? '炎热' : '凉爽'}变为${newValue ? '炎热' : '凉爽'}`);
    }
  }
}).mount('#watch-basic');
</script>
运行结果

今天天气很{{ info }}

2. 深度侦听与立即执行

当需要侦听对象内部属性变化或立即执行回调时，可以使用深度侦听和立即执行选项：

深度侦听与立即执行
<div id="watch-advanced">
  <h3>a的值是{{ numbers.a }}</h3>
  <button @click="numbers.a++">点我a+1</button>
  <button @click="numbers.b++">点我b+1</button>
</div>

<script>
Vue.createApp({
  data() {
    return {
      numbers: {
        a: 1,
        b: 2
      }
    }
  },
  watch: {
    // 侦听numbers对象的a属性
    'numbers.a': {
      handler(newValue, oldValue) {
        console.log(`a从${oldValue}变为${newValue}`);
      }
    },
    // 深度侦听整个numbers对象
    numbers: {
      deep: true, // 深度侦听
      immediate: true, // 立即执行
      handler(newValue, oldValue) {
        console.log('numbers对象发生变化', newValue);
      }
    }
  }
}).mount('#watch-advanced');
</script>
运行结果

a的值是{{ numbers.a }}

侦听器使用注意事项

  • 深度侦听性能开销大 - 仅在必要时使用deep选项
  • 避免在侦听器中修改自身依赖的数据 - 可能导致无限循环
  • 异步操作 - 侦听器是处理异步操作的理想场所

计算属性 vs 侦听器

如何选择？

虽然计算属性和侦听器都可以响应数据变化，但它们有不同的适用场景：

  • 计算属性 - 用于声明式派生值，结果会被缓存
  • 侦听器 - 用于响应数据变化执行操作（尤其是异步操作）

关键区别

特性 计算属性 侦听器
主要用途 派生新数据 响应数据变化执行操作
缓存 是，基于依赖缓存 否，每次变化都执行
异步支持 不支持 支持
语法 声明式，像普通属性 命令式，需定义处理函数
返回值 必须有返回值 不需要返回值
1
何时使用计算属性
当需要基于现有数据计算派生值时（如全名、总价、过滤列表）
2
何时使用侦听器
当需要在数据变化时执行异步操作或复杂逻辑时（如API调用、验证、日志记录）
3
组合使用
在实际应用中，计算属性和侦听器经常组合使用，各自发挥优势
黄金法则： 优先使用计算属性，当需要执行异步操作或副作用时才使用侦听器。

综合练习：用户信息面板

练习要求

创建一个用户信息面板，结合使用计算属性和侦听器：

  • 使用计算属性生成用户全名和简介
  • 使用侦听器监控年龄变化并给出提示
  • 使用侦听器监控城市变化并模拟API调用
用户信息面板完整代码
<div id="practice-app">
  <h3>用户信息面板</h3>
  
  <div class="input-group">
    姓: <input type="text" v-model="user.firstName">
  </div>
  
  <div class="input-group">
    名: <input type="text" v-model="user.lastName">
  </div>
  
  <div class="input-group">
    年龄: <input type="number" v-model="user.age">
  </div>
  
  <div class="input-group">
    城市: <input type="text" v-model="user.city">
  </div>
  
  <div class="user-info">
    <h4>用户简介:</h4>
    <p>{{ userProfile }}</p>
    
    <h4 v-if="ageMessage">年龄提示:</h4>
    <p class="highlight">{{ ageMessage }}</p>
    
    <h4 v-if="cityInfo">城市信息:</h4>
    <p>{{ cityInfo }}</p>
  </div>
</div>

<script>
Vue.createApp({
  data() {
    return {
      user: {
        firstName: '张',
        lastName: '三',
        age: 25,
        city: '北京'
      },
      ageMessage: '',
      cityInfo: ''
    }
  },
  computed: {
    // 计算用户全名
    fullName() {
      return this.user.firstName + ' ' + this.user.lastName;
    },
    // 计算用户简介
    userProfile() {
      return `${this.fullName}，${this.user.age}岁，来自${this.user.city}`;
    }
  },
  watch: {
    // 侦听年龄变化
    'user.age': {
      handler(newAge, oldAge) {
        if (newAge > 100) {
          this.ageMessage = '您输入的年龄异常，请确认！';
        } else if (newAge >= 60) {
          this.ageMessage = '老年阶段，注意健康保养';
        } else if (newAge >= 30) {
          this.ageMessage = '中年阶段，事业高峰期';
        } else if (newAge >= 18) {
          this.ageMessage = '青年阶段，充满活力';
        } else {
          this.ageMessage = '未成年阶段，需要监护人';
        }
        
        console.log(`年龄从${oldAge}变为${newAge}`);
      },
      immediate: true // 初始化时立即执行
    },
    // 侦听城市变化（模拟API调用）
    'user.city': {
      handler(newCity) {
        this.cityInfo = `正在查询${newCity}的信息...`;
        
        // 模拟API请求延迟
        setTimeout(() => {
          this.cityInfo = `已获取${newCity}的最新信息：人口约1000万，著名景点有故宫、长城等。`;
        }, 1500);
      },
      immediate: true // 初始化时立即执行
    }
  }
}).mount('#practice-app');
</script>
