事件基础

什么是事件？

事件是发生在HTML元素上的某些特定的事情，它的目的是能够使页面具有某些行为，执行某些“动作”。

事件流

由于DOM是树形结构，因此当某个子元素被点击时，它的父元素实际上也被点击了，它的父元素的父元素也被点击了，一直到根元素。因此一个“鼠标点击”产生的并不是一个事件，而是一系列事件，这一系列事件就组成了“事件流”。

1
捕获阶段
从最外层的根元素html开始依次向下。
2
到达阶段
事件到达目标元素时。
3
冒泡阶段
然后再依次向上回到根元素。

v-on指令

v-on指令基础

在Vue开发中，需要给DOM元素绑定事件，利用事件实现交互效果，这时可以利用事件绑定指令 v-on 来实现。

基本语法：

<标签名 v-on:事件名="事件处理器"></标签名>

事件名即DOM中的事件名，例如 click、input、keyup 等。

事件处理器可以是方法名或内联JavaScript语句。逻辑复杂时，事件处理器建议使用方法名，方法在<script>标签中定义；逻辑简单，只有一行代码时，使用内联JavaScript语句。

v-on的使用方法

使用方式 适用场景 示例
方法名 逻辑复杂 v-on:click="handleClick"
内联语句 逻辑简单，只有一行代码 v-on:click="count++"
简写形式 所有情况，v-on: 可以简写为 @ @click="handleClick"

v-on示例

v-on 基本用法
<template>
  <div>
    <!-- 使用方法名作为事件处理器 -->
    <button v-on:click="showInfo">点我提示</button>
    <!-- 使用内联JavaScript语句作为事件处理器，并使用v-on简写形式 -->
    <button @click="count++">计数器: {{ count }}</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      count: 0
    }
  },
  methods: {
    showInfo() {
      // 使用自定义消息盒子替代 alert，符合 Canvas 规范
      this.showMessage('欢迎学习Vue事件处理！');
    }
  }
}
</script>

事件对象

什么是事件对象？如何获取？

事件对象是JavaScript原生事件对象，可以获取与事件相关的信息，例如事件类型、目标元素等。

Vue中可以通过$event来访问原生DOM事件。

在Vue中获取事件对象有两种主要方式：

  1. 如果事件处理器没有传入参数，则默认的第一个参数就是事件对象。
  2. 如果事件处理器需要传入自定义参数，可以使用$event显式传入事件对象。

通过参数获取事件对象

通过参数获取事件对象
<template>
  <div>
    <!-- click 事件触发时，原生事件对象会作为 showInfo 方法的第一个参数传入 -->
    <button @click="showInfo">点我显示事件信息</button>
    <p>事件信息: {{ eventMessage }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      eventMessage: '点击按钮获取事件信息'
    }
  },
  methods: {
    // Vue 会自动将原生事件对象作为第一个参数传入
    showInfo(event) {
      this.eventMessage = `事件类型: ${event.type}, 目标标签: ${event.target.tagName}`;
      console.log('事件对象:', event); // 可以在控制台查看完整事件对象
    }
  }
}
</script>

通过$event获取事件对象及参数传递顺序

$event 变量与参数传递

当事件处理器需要接收原生事件对象，同时又需要传递额外的自定义参数时，可以使用特殊的 $event 变量。

$event 会显式地引用原生 DOM 事件对象。

参数传递顺序：

在方法调用中，$event 变量可以与自定义参数混合使用。无论 $event 放置在参数列表的哪个位置，它都代表原生事件对象。Vue 会智能地识别它并正确地传递原生事件。

@click="myMethod(param1, $event, param2)"
使用 $event 传递事件对象和自定义参数
<template>
  <div>
    <!-- 示例1: 传递自定义参数和 $event -->
    <button @click="showInfo2('自定义文本', $event)">带自定义参数和$event</button>
    <!-- 示例2: 仅传递 $event -->
    <button @click="showInfo1($event)">只传 $event</button>
    <p>{{ message }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: ''
    }
  },
  methods: {
    // 仅接收事件对象
    showInfo1(event) {
      this.message = `事件类型: ${event.type}`;
      console.log('showInfo1 - 接收到的事件对象:', event);
    },
    // 接收自定义参数和事件对象
    showInfo2(text, event) {
      this.message = `${text} - 目标标签: ${event.target.tagName}`;
      console.log('showInfo2 - 自定义文本:', text);
      console.log('showInfo2 - 事件对象:', event);
    }
  }
}
</script>

事件修饰符

什么是事件修饰符？

事件修饰符是Vue提供的特殊后缀，用于修饰事件的行为。修饰符写在事件名称之后，用点 . 连接。

多个事件修饰符可以串联使用。

常用事件修饰符详解

修饰符 功能描述 示例
.stop 阻止事件冒泡。 @click.stop
.prevent 阻止事件的默认行为。 @click.prevent
.once 使事件只触发一次。用于阻止事件的多次触发，让事件只触发一次。 @click.once
.capture 实现事件捕获的功能。事件捕获的顺序和冒泡的顺序相反，在DOM树中的方向是由外向内。 @click.capture
.self 使DOM元素只有自身触发事件时才执行事件方法。 @click.self
.passive 监听滚动事件的功能。主要用于优化移动端设备的滚屏性能。添加.passive事件修饰符后会优先响应滚动事件而不是滚动事件的回调函数，从而可提升性能。 @scroll.passive

阻止默认行为(.prevent) 示例

使用 .prevent 阻止默认行为
<template>
  <div>
    <!-- 默认行为会跳转页面 -->
    <a href="https://vuejs.org" @click="log('普通链接被点击，将跳转')">
      普通链接（会跳转）
    </a>
    
    <!-- 使用.prevent阻止默认跳转行为 -->
    <a href="https://vuejs.org" @click.prevent="log('阻止跳转的链接被点击')">
      阻止跳转的链接
    </a>

    <!-- 阻止表单的默认提交刷新页面行为 -->
    <form @submit.prevent="handleSubmit">
        <input type="text" placeholder="输入内容">
        <button type="submit">提交 (阻止刷新)</button>
    </form>
    
    <div class="event-log">
      <div v-for="(log, index) in logs" :key="index">{{ log }}</div>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      logs: []
    }
  },
  methods: {
    log(message) {
      this.logs.unshift(`${new Date().toLocaleTimeString()}: ${message}`);
      if (this.logs.length > 5) this.logs.pop(); // 限制日志数量
    },
    handleSubmit() {
        this.log('表单被提交，但默认刷新行为被阻止');
    }
  }
}
</script>

    <div class="bubble-child" @click.stop="log('带.stop的子元素被点击 (阻止冒泡)')">

    </div>

    </button>

    </div>
  </div>
</template>

<script>

  data() {
    return {
      logs: []
    }
  },
  methods: {
    log(message) {
      this.logs.unshift(`${new Date().toLocaleTimeString()}: ${message}`);
      if (this.logs.length > 5) this.logs.pop();

  }
}
</script>

事件捕获(.capture) 示例

使用 .capture 示例
<template>
  <!-- 父元素使用 .capture 监听，事件会在捕获阶段被处理 -->
  <div class="bubble-container" @click.capture="log('我是父元素的事件')">
    <p>父元素 (捕获)</p>
    <!-- 子元素普通监听，会在冒泡阶段被处理 -->
    <button @click="log('我是子元素的事件')">事件捕获</button>
    <div class="event-log">
      <div v-for="(log, index) in logs" :key="index">{{ log }}</div>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      logs: []
    }
  },
  methods: {
    log(message) {
      this.logs.unshift(`${new Date().toLocaleTimeString()}: ${message}`);
      if (this.logs.length > 5) this.logs.pop();
    }
  }
}
</script>

自身触发(.self) 示例

使用 .self 示例
<template>
  <!-- 父元素使用 .self 监听，只有点击其自身时才触发 -->
  <div class="bubble-container" @click.self="log('父元素自身被点击')">
    <p>父元素 (只有自身点击才触发)</p>
    <!-- 点击子元素会冒泡，但父元素的 .self 监听器会忽略它 -->
    <button @click="log('子元素被点击')">点击子元素</button>
    <div class="event-log">
      <div v-for="(log, index) in logs" :key="index">{{ log }}</div>
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      logs: []
    }
  },
  methods: {
    log(message) {
      this.logs.unshift(`${new Date().toLocaleTimeString()}: ${message}`);
      if (this.logs.length > 5) this.logs.pop();
    }
  }
}
</script>

被动事件(.passive) 示例

使用 .passive 示例
<template>
  <!-- 使用 .passive 优化滚动性能 -->
  <div class="scroll-container" @scroll.passive="handleScroll">
    <p>请在此区域滚动，观察控制台输出。</p>
    <p>添加 .passive 事件修饰符后会优先响应滚动事件而不是滚动事件的回调函数，从而可提升性能。</p>
    <p v-for="n in 50" :key="n">滚动内容 {{ n }}</p>
  </div>
  <div class="event-log">
    <div v-for="(log, index) in logs" :key="index">{{ log }}</div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      logs: []
    }
  },
  methods: {
    handleScroll(event) {
      // .passive 修饰符告诉浏览器，你不会在这里调用 event.preventDefault()
      // 因此，即使回调函数执行较慢，浏览器也可以继续平滑滚动
      this.logs.unshift(`${new Date().toLocaleTimeString()}: 滚动事件触发, 滚动位置: ${event.target.scrollTop.toFixed(2)}`);
      if (this.logs.length > 5) this.logs.pop();
    }
  }
}
</script>
<style>
.scroll-container {
  height: 200px;
  overflow-y: scroll;
  border: 1px solid #ccc;
  padding: 10px;
  margin-top: 20px;
  background-color: #f9f9f9;
}
</style>

事件修饰符使用技巧

1. 多个修饰符可以串联使用。

2. 修饰符的顺序很重要，Vue会按顺序执行。

键盘事件修饰符

键盘事件修饰符详解

Vue 提供了用于监听特定键盘按键的修饰符。

常用按键修饰符：

  • .enter
  • .tab
  • .delete (捕获“删除”和“退格”键)
  • .esc
  • .space
  • .up
  • .down
  • .left
  • .right

系统修饰符：

  • .ctrl
  • .alt
  • .shift
  • .meta

.exact修饰符：

控制修饰符组合，只有当确切地按下某个修饰符时才触发事件。

键盘事件修饰符示例

键盘事件修饰符
<template>
  <div>
    <p>请在以下输入框中尝试按键:</p>
    <input type="text" @keyup.enter="handleEnter" placeholder="按回车键触发">
    <input type="text" @keyup.esc="handleEsc" placeholder="按Esc键触发">
    <!-- PDF中示例的组合键 -->
    <input type="text" @keyup.ctrl.enter="handleCtrlEnter" placeholder="按Ctrl + Enter触发">
    <!-- PDF中.exact修饰符的示例 -->
    <input type="text" @click.ctrl="handleCtrlClick" placeholder="按Ctrl + 点击我 (无论是否有其他修饰符)">
    <input type="text" @click.ctrl.exact="handleCtrlExactClick" placeholder="按Ctrl + 点击我 (仅当Ctrl按下，无其他修饰符)">
    <input type="text" @click.exact="handleExactClick" placeholder="仅普通点击 (无任何修饰符)">

    <p>最新事件: <span>{{ keyMessage }}</span></p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      keyMessage: '等待按键...'
    }
  },
  methods: {
    handleEnter() {
      this.keyMessage = '回车键 (Enter) 被按下！';
    },
    handleEsc() {
      this.keyMessage = 'Esc 键被按下！';
    },
    handleCtrlEnter() {
      this.keyMessage = 'Ctrl + Enter 组合键被按下！';
    },
    // 以下为PDF中.exact修饰符的示例对应
    handleCtrlClick() {
        this.keyMessage = 'Ctrl 键被按下 (无论是否有其他修饰符)';
    },
    handleCtrlExactClick() {
        this.keyMessage = '仅 Ctrl 键被按下 (无其他修饰符)！';
    },
    handleExactClick() {
        this.keyMessage = '仅普通点击 (无任何修饰符)！';
    }
  }
}
</script>

鼠标事件修饰符

鼠标事件修饰符详解

Vue 也提供了用于监听特定鼠标按键的修饰符。

  • .left：左键点击。
  • .right：右键点击。
  • .middle：中键点击。

鼠标事件修饰符示例

鼠标事件修饰符
<template>
  <div>
    <p>请用不同鼠标按键点击以下按钮:</p>
    <button @click.left="handleLeftClick">左键点击我</button>
    <!-- 阻止右键菜单的默认行为 -->
    <button @click.right.prevent="handleRightClick">右键点击我 (阻止默认菜单)</button>
    <button @click.middle="handleMiddleClick">中键点击我</button>
    <p>最新事件: <span>{{ mouseMessage }}</span></p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      mouseMessage: '等待鼠标点击...'
    }
  },
  methods: {
    handleLeftClick() {
      this.mouseMessage = '鼠标左键被点击！';
    },
    handleRightClick() {
      this.mouseMessage = '鼠标右键被点击！';
    },
    handleMiddleClick() {
      this.mouseMessage = '鼠标中键被点击！';
    }
  }
}
</script>
