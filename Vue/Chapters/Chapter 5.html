Vue.js 结构渲染

结构渲染是Vue.js的核心功能之一，它允许开发者根据数据状态动态控制DOM元素的显示和渲染方式。

什么是结构渲染？

结构渲染是指根据应用程序的状态动态生成和更新DOM元素的过程。Vue.js提供了两种主要的结构渲染指令：

  • 条件渲染 - 根据条件显示或隐藏元素（v-if, v-show）
  • 列表渲染 - 根据数组或对象动态生成列表（v-for）

这些指令使开发者能够创建动态、响应式的用户界面，根据数据变化自动更新DOM结构。

条件渲染

什么是条件渲染？

条件渲染允许你根据特定条件显示或隐藏DOM元素。在Vue中，主要通过两个指令实现：

  • v-if - 根据条件在DOM树中添加或移除元素
  • v-show - 通过CSS的display属性控制元素的显示/隐藏

条件渲染在需要根据不同状态显示不同UI元素的场景中非常有用，例如用户登录状态、权限控制、表单步骤等。

1. v-if 指令

v-if 指令根据表达式的值（真/假）来决定是否渲染元素。当条件为false时，元素不会出现在DOM树中。

v-if 基本用法
<div id="vif-example">
  <p v-if="isVisible">这个段落会根据条件显示或隐藏</p>
  <button @click="toggleVisibility">
    {{ isVisible ? '隐藏' : '显示' }}内容
  </button>
</div>

<script>
Vue.createApp({
  data() {
    return {
      isVisible: true
    }
  },
  methods: {
    toggleVisibility() {
      this.isVisible = !this.isVisible;
    }
  }
}).mount('#vif-example');
</script>
运行结果

这个段落会根据条件显示或隐藏

2. v-else 和 v-else-if

v-if 可以与 v-else-if 和 v-else 配合使用，实现更复杂的条件逻辑。

v-if 结合 v-else-if 和 v-else
<div id="vif-else-example">
  <div>小明的学习评定等级为：</div>
  <p v-if="type === 'A'">优秀</p>
  <p v-else-if="type === 'B'">良好</p>
  <p v-else>差</p>
  
  <button @click="type = 'A'">切换成优秀</button>
  <button @click="type = 'B'">切换成良好</button>
  <button @click="type = 'C'">切换成差</button>
</div>

<script>
Vue.createApp({
  data() {
    return {
      type: 'B'
    }
  }
}).mount('#vif-else-example');
</script>

3. v-show 指令

v-show 与 v-if 类似，但不会从DOM中移除元素，而是通过CSS的display属性控制元素的显示/隐藏。

v-show 基本用法
<div id="vshow-example">
  <p v-show="isVisible">这个段落通过v-show控制显示/隐藏</p>
  <p v-if="isVisible">这个段落通过v-if控制显示/隐藏</p>
  <button @click="isVisible = !isVisible">
    显示/隐藏
  </button>
</div>

<script>
Vue.createApp({
  data() {
    return {
      isVisible: true
    }
  }
}).mount('#vshow-example');
</script>

列表渲染

什么是列表渲染？

列表渲染允许你基于数组或对象动态生成DOM元素列表。Vue中通过 v-for 指令实现列表渲染。

v-for 指令的基本语法：

  • 遍历数组：v-for="(item, index) in items"
  • 遍历对象：v-for="(value, key, index) in object"
  • 遍历数字：v-for="n in 10" (生成1-10)

列表渲染在需要展示动态数据集合的场景中非常有用，如商品列表、用户列表、消息列表等。

1. 使用 v-for 遍历数组

v-for 最常用于遍历数组，为每个数组项生成对应的DOM元素。

遍历一维数组
<div id="vfor-array-example">
  <div v-for="(item, index) in list" :key="index">
    索引: {{ index }} --- 内容: {{ item }}
  </div>
</div>

<script>
Vue.createApp({
  data() {
    return {
      list: ['HTML', 'CSS', 'JavaScript']
    }
  }
}).mount('#vfor-array-example');
</script>
运行结果
索引: {{ index }} --- 内容: {{ item }}

2. 使用 v-for 遍历对象数组

在实际应用中，我们经常需要遍历对象数组，每个对象包含多个属性。

遍历对象数组
<div id="vfor-object-array-example">
  <div v-for="item in list" :key="item.id">
    ID: {{ item.id }} --- 内容: {{ item.message }}
  </div>
</div>

<script>
Vue.createApp({
  data() {
    return {
      list: [
        { id: 1, message: '梅' },
        { id: 2, message: '兰' },
        { id: 3, message: '竹' },
        { id: 4, message: '菊' }
      ]
    }
  }
}).mount('#vfor-object-array-example');
</script>
运行结果
ID: {{ item.id }} --- 内容: {{ item.message }}

3. 使用 v-for 遍历对象

v-for 也可以用于遍历对象的属性，获取键名和键值。

遍历对象
<div id="vfor-object-example">
  <div v-for="(value, name) in user" :key="name">
    属性名: {{ name }} --- 属性值: {{ value }}
  </div>
</div>

<script>
Vue.createApp({
  data() {
    return {
      user: {
        id: 11, 
        name: '小明', 
        gender: '男',
        age: 20
      }
    }
  }
}).mount('#vfor-object-example');
</script>
运行结果
属性名: {{ name }} --- 属性值: {{ value }}

4. 使用 key 属性

在 v-for 中使用 :key 属性非常重要，它可以帮助Vue高效地更新DOM。

为什么需要key属性？

key属性为每个列表项提供唯一的标识符，当列表发生变化时，Vue可以：

  • 精确识别哪些元素被添加、删除或重新排序
  • 重用和重新排序现有元素而不是重新渲染整个列表
  • 避免不必要的DOM操作，提高性能

最佳实践：使用唯一值作为key（如ID），避免使用索引作为key（当列表顺序可能变化时）

v-if 与 v-show 比较

如何选择？

v-if 和 v-show 都可以控制元素的显示/隐藏，但它们的实现方式和适用场景不同：

  • v-if - 是"真正的"条件渲染，元素会被完全销毁和重建
  • v-show - 只是简单地切换CSS的display属性

简单来说：v-if有更高的切换开销，v-show有更高的初始渲染开销。

关键区别

特性 v-if v-show
实现方式 条件为false时从DOM中移除元素 使用CSS display: none 隐藏元素
初始渲染 惰性渲染，条件为true才渲染 无论条件如何都渲染，只是显示/隐藏
切换开销 较高（需要销毁/重建DOM） 较低（只是CSS切换）
使用场景 切换不频繁的场景 需要频繁切换显示/隐藏的场景
与v-else配合 支持 不支持
1
何时使用 v-if
当元素很少切换显示状态时（如权限控制、初始化不显示的元素）
2
何时使用 v-show
当元素需要频繁切换显示状态时（如标签页切换、折叠面板）
3
性能考虑
对于需要频繁切换的元素，使用v-show可以避免不必要的DOM操作

练习：心情应用

练习要求

创建一个心情应用，用户可以选择城市和输入姓名，点击"赞"按钮后，会显示一条消息并添加到列表中。

功能要求：

  • 使用v-model绑定城市和姓名输入
  • 使用计算属性生成完整的消息
  • 使用v-for渲染消息列表
  • 使用v-show控制图片的显示/隐藏
心情应用完整代码
<div id="practice-app">
  <h3>此刻的心情</h3>
  
  <img v-show="showImage" src="https://picsum.photos/400/300?nature" 
       alt="心情图片" width="400" height="300">
  
  <div>
    <button @click="showImage = !showImage">
      {{ showImage ? '隐藏图片' : '显示图片' }}
    </button>
  </div>
  
  <div class="input-group">
    城市：<input type="text" v-model="city">
  </div>
  
  <div class="input-group">
    姓名：<input type="text" v-model="name">
  </div>
  
  <button @click="addLike">赞一下</button>
  
  <h4 v-if="likes.length > 0">收到的赞：</h4>
  <ul>
    <li v-for="(like, index) in likes" :key="index">
      {{ like.message }} ({{ like.time }})
    </li>
  </ul>
</div>

<script>
Vue.createApp({
  data() {
    return {
      city: '',
      name: '',
      showImage: true,
      likes: []
    }
  },
  computed: {
    fullMessage() {
      if (this.city && this.name) {
        return `${this.city}的${this.name}赞了你`;
      }
      return '请填写城市和姓名';
    }
  },
  methods: {
    addLike() {
      if (!this.city || !this.name) {
        alert('请填写城市和姓名');
        return;
      }
      
      const now = new Date();
      const timeString = `${now.getHours()}:${now.getMinutes()}:${now.getSeconds()}`;
      
      this.likes.unshift({
        message: this.fullMessage,
        time: timeString
      });
    }
  }
}).mount('#practice-app');
</script>
