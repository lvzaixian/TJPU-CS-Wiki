选项式API与组合式API

Vue.js 的两种API风格

Vue 3支持两种编写组件的API风格：选项式API（Options API）和组合式API（Composition API）。

  • 选项式API - Vue 2的传统写法，通过data、methods等选项组织代码
  • 组合式API - Vue 3的新写法，通过setup()函数组织所有逻辑代码

组合式API更适合大型项目，它解决了选项式API在复杂组件中代码分散的问题。

API语法模板总结

API类型 语法模板 说明
选项式API data() { return { ... } } 数据定义
选项式API methods: { ... } 方法定义
选项式API computed: { ... } 计算属性
组合式API const data = ref(value) 响应式数据
组合式API const computedValue = computed(() => ...) 计算属性
组合式API watch(source, callback) 侦听器
// 选项式API完整示例
export default {
  data() {
    return { count: 0 }
  },
  methods: {
    increment() { this.count++ }
  }
}
// 组合式API完整示例
<script setup>
import { ref, computed } from 'vue'
const count = ref(0)
const increment = () => { count.value++ }
const double = computed(() => count.value * 2)
</script>

选项式API示例

选项式API结构
<script>
export default {
  // 数据属性
  data() {
    return {
      count: 0
    }
  },
  
  // 方法
  methods: {
    increment() {
      this.count++;
    }
  },
  
  // 计算属性
  computed: {
    doubleCount() {
      return this.count * 2;
    }
  },
  
  // 侦听器
  watch: {
    count(newValue, oldValue) {
      console.log(`计数从 ${oldValue} 变为 ${newValue}`);
    }
  }
}
</script>

组合式API示例

组合式API结构
<script setup>
import { ref, computed, watch } from 'vue';

// 响应式数据
const count = ref(0);

// 方法
function increment() {
  count.value++;
}

// 计算属性
const doubleCount = computed(() => count.value * 2);

// 侦听器
watch(count, (newValue, oldValue) => {
  console.log(`计数从 ${oldValue} 变为 ${newValue}`);
});
</script>
运行结果

当前计数: {{ count }}

双倍计数: {{ doubleCount }}

选项式API 组合式API
逻辑分散在多个选项中 逻辑集中在一个setup函数中
适合小型项目 适合大型复杂项目
学习曲线平缓 需要理解响应式API
this上下文访问数据 直接访问响应式变量

生命周期函数

组件生命周期

每个Vue组件从创建到销毁都会经历一系列阶段，这些阶段称为组件的生命周期。

Vue提供了一系列生命周期钩子函数，允许我们在特定阶段执行自定义逻辑。

理解生命周期对于掌握组件行为至关重要，它决定了何时可以访问DOM、何时更新数据等。

生命周期钩子函数对比

阶段 选项式API 组合式API 说明
创建前 beforeCreate - 实例初始化之后，数据观测之前调用
创建后 created - 实例创建完成后调用，可以访问数据
挂载前 beforeMount onBeforeMount 挂载开始之前调用，相关render函数首次被调用
挂载后 mounted onMounted 挂载完成后调用，可以访问DOM元素
更新前 beforeUpdate onBeforeUpdate 数据更新时调用，发生在虚拟DOM打补丁之前
更新后 updated onUpdated 数据更改导致的虚拟DOM重新渲染后调用
卸载前 beforeUnmount onBeforeUnmount 实例销毁之前调用
卸载后 unmounted onUnmounted 实例销毁后调用

关键点

组合式API中，beforeCreate和created生命周期钩子被setup()函数替代。

// 组合式API生命周期使用示例
<script setup>
import { onMounted, onUnmounted } from 'vue';

onMounted(() => {
  // 组件挂载后执行操作
  console.log('组件已挂载');
});

onUnmounted(() => {
  // 组件卸载前执行清理
  console.log('组件即将卸载');
});
</script>

创建后

挂载前

生命周期使用示例

组合式API生命周期
<script setup>
import { ref, onMounted, onUnmounted } from 'vue';

const timer = ref(null);
const seconds = ref(0);

// 组件挂载后启动计时器
onMounted(() => {
  timer.value = setInterval(() => {
    seconds.value++;
  }, 1000);
});

// 组件卸载前清除计时器
onUnmounted(() => {
  clearInterval(timer.value);
});
</script>

<template>
  <p>组件已运行 {{ seconds }} 秒</p>
</template>
运行结果

组件已运行 {{ seconds }} 秒

组件的注册和引用

组件注册方式

在Vue中，组件需要注册后才能使用。Vue提供两种注册方式：全局注册和局部注册。

  • 全局注册 - 在应用层面注册，任何地方都可使用
  • 局部注册 - 在组件内注册，只能在当前组件使用

全局注册适合频繁使用的通用组件，局部注册适合特定功能组件。

组件注册语法模板

注册类型 语法模板 说明
全局注册 app.component('ComponentName', Component) 在main.js中使用，全局可用
局部注册
(选项式API)		 components: { ComponentName } 在组件选项中注册
局部注册
(组合式API)		 import Component from './Component.vue' 导入后直接在模板中使用
// 全局注册示例 (src/main.js)
import { createApp } from 'vue';
import App from './App.vue';
import MyComponent from './components/MyComponent.vue';

const app = createApp(App);
app.component('MyComponent', MyComponent);
app.mount('#app');
// 局部注册示例 (选项式API)
<script>
import LocalComponent from './LocalComponent.vue';

export default {
  components: {
    LocalComponent,
    // 或自定义名称: MyLocalComponent: LocalComponent
  }
}
</script>
// 局部注册示例 (组合式API)
<script setup>
import LocalComponent from './LocalComponent.vue';
</script>

<!-- 直接在模板中使用 -->
<template>
  <LocalComponent />
</template>

全局注册

在main.js中全局注册组件
// src/main.js
import { createApp } from 'vue';
import App from './App.vue';
import GlobalComponent from './components/GlobalComponent.vue';

const app = createApp(App);

// 全局注册组件
app.component('GlobalComponent', GlobalComponent);

app.mount('#app');

局部注册

在组件内局部注册
<script>
import LocalComponent from './LocalComponent.vue';

export default {
  components: {
    // 注册为 
    LocalComponent,
    
    // 自定义名称注册
    MyLocalComponent: LocalComponent
  }
}
</script>

<!-- 使用setup语法糖 -->
<script setup>
import LocalComponent from './LocalComponent.vue';
</script>

组件命名最佳实践

1. 使用帕斯卡命名法(PascalCase)命名组件文件：MyComponent.vue

2. 在模板中可以使用帕斯卡命名法或短横线命名法(kebab-case)：

    <MyComponent> 或 <my-component>

3. 避免使用HTML原生标签名作为组件名

解决样式冲突

使用scoped样式

  margin: 10px;

Props属性

父组件向子组件传值

Props是父组件向子组件传递数据的主要方式。

使用步骤：

  1. 在子组件中声明props
  2. 在父组件中通过属性传递数据
  3. 在子组件中使用props数据

Props遵循单向数据流原则，父组件数据变化会自动更新子组件，但子组件不能直接修改props。

Props声明与验证

类型 语法模板 说明
基础声明 defineProps(['propA', 'propB']) 简单props声明
类型声明 defineProps({ propA: String }) 指定props类型
默认值 default: 'value' 设置props默认值
必填项 required: true 标记必须传递的prop
自定义验证 validator(value) { ... } 自定义验证函数
// 带验证的Props声明
<script setup>
const props = defineProps({
  // 基础类型检查
  age: Number,
  
  // 多个类型
  id: [String, Number],
  
  // 必填项
  name: {
    type: String,
    required: true
  },
  
  // 带默认值
  size: {
    type: String,
    default: 'medium'
  },
  
  // 自定义验证函数
  status: {
    validator(value) {
      return ['success', 'warning', 'error'].includes(value);
    }
  }
});
</script>

Props最佳实践

  • 明确类型：为每个prop指定类型，便于理解和调试
  • 设置默认值：为可选prop提供默认值
  • 标记必需prop：使用required: true标记必须传递的prop
  • 避免修改prop：如果需要基于prop修改数据，使用data或computed属性

声明Props

在子组件中声明props
<!-- 子组件 ChildComponent.vue -->
<script setup>
// 基础类型声明
const props = defineProps({
  title: String,
  count: Number,
  isActive: Boolean,
  items: Array,
  user: Object
});

// 带验证的声明
const props = defineProps({
  // 基础类型检查
  age: Number,
  
  // 多个类型
  id: [String, Number],
  
  // 必填项
  name: {
    type: String,
    required: true
  },
  
  // 带默认值
  size: {
    type: String,
    default: 'medium'
  },
  
  // 自定义验证函数
  status: {
    validator(value) {
      return ['success', 'warning', 'error'].includes(value);
    }
  }
});
</script>

组件通信

组件间通信方式

Vue提供了多种组件间通信方式：

  • Props - 父组件向子组件传递数据
  • 自定义事件 - 子组件向父组件传递数据
  • 依赖注入 - 跨层级组件通信

选择合适的通信方式取决于组件间的关系和通信需求。

组件通信方法总结

通信方式 语法模板 说明
Props <Child :prop="value" /> 父→子单向数据流
自定义事件 emit('event', data) 子→父通信
依赖注入 provide(key, value) 跨层级提供数据
依赖注入 inject(key) 跨层级注入数据
// 自定义事件示例 (子组件)
<script setup>
const emit = defineEmits(['updateCount']);

function increment() {
  emit('updateCount', 5); // 触发事件
}
</script>

// 父组件监听事件
<Child @update-count="handleUpdate" />

<script setup>
const handleUpdate = (value) => {
  count.value += value;
}
</script>
// 依赖注入示例 (祖先组件)
<script setup>
import { provide, ref } from 'vue';

const theme = ref('light');
provide('appTheme', {
  theme,
  toggleTheme: () => {
    theme.value = theme.value === 'light' ? 'dark' : 'light';
  }
});
</script>

// 后代组件使用
<script setup>
import { inject } from 'vue';

const { theme, toggleTheme } = inject('appTheme');
</script>

子组件向父组件通信（自定义事件）

使用自定义事件
<!-- 子组件 -->
<script setup>
const emit = defineEmits(['updateCount']);

function increment() {
  emit('updateCount', 5); // 触发事件并传递值
}
</script>

<template>
  <button @click="increment">增加5</button>
</template>

<!-- 父组件 -->
<template>
  <ChildComponent @update-count="handleUpdate" />
  <p>当前值: {{ count }}</p>
</template>

<script setup>
import ChildComponent from './ChildComponent.vue';
import { ref } from 'vue';

const count = ref(10);

function handleUpdate(value) {
  count.value += value;
}
</script>

跨级组件通信（依赖注入）

使用provide/inject
<!-- 祖先组件 -->
<script setup>
import { provide, ref } from 'vue';

const theme = ref('light');

function toggleTheme() {
  theme.value = theme.value === 'light' ? 'dark' : 'light';
}

// 提供数据和函数
provide('appTheme', {
  theme,
  toggleTheme
});
</script>

<!-- 后代组件（任意层级） -->
<script setup>
import { inject } from 'vue';

const { theme, toggleTheme } = inject('appTheme');
</script>

<template>
  <div :class="theme">
    <p>当前主题: {{ theme }}</p>
    <button @click="toggleTheme">切换主题</button>
  </div>
</template>
运行结果

当前主题: {{ theme }}
