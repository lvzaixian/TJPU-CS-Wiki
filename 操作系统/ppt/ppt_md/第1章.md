## 幻灯片 11

这个程序是一个简单的C语言程序，演示了如何在Linux环境下使用`fork()`和`execlp()`函数来创建子进程并执行另一个程序。下面是对程序的逐行解释：

#include <stdio.h>
这行代码包含了标准输入输出库，提供了`printf()`和`fprintf()`等函数。
void main(int argc, char *argv[])
这是程序的主函数入口，`argc`表示命令行参数的数量，`argv`是一个字符串数组，存储了命令行参数。
{
    int pid;
声明一个整型变量`pid`，用于存储`fork()`函数的返回值。
    pid = fork();
调用`fork()`函数创建一个新进程。`fork()`函数会返回两次：在父进程中返回子进程的PID，在子进程中返回0。
    if (pid < 0) { /* error occurred */
        fprintf(stderr, "Fork Failed");
        exit(-1);
    }
如果`fork()`返回值小于0，表示创建子进程失败。程序会输出错误信息并退出。
    else if (pid == 0) { /* child process */
        execlp("/bin/ls", "ls", NULL);
    }

如果`fork()`返回值为0，表示当前进程是子进程。调用`execlp()`函数执行`/bin/ls`命令，列出当前目录的内容。`execlp()`函数的第一个参数是可执行文件的路径，第二个参数是命令名，第三个参数是NULL，表示参数列表的结束。
    else { /* parent will wait for the child to complete */
        wait(NULL);
        printf("Child Complete");
        exit(0);
    }
}
如果`fork()`返回值大于0，表示当前进程是父进程。调用`wait(NULL)`函数等待子进程完成。子进程完成后，父进程输出“Child Complete”并退出。


总结：
• 这个程序首先创建一个子进程。
• 如果创建失败，输出错误信息并退出。
• 如果是子进程，执行`/bin/ls`命令。
• 如果是父进程，等待子进程完成并输出“Child Complete”。

## 幻灯片 89

课程思政小讲堂

了解Windows应用初期，Linux问世，那现在国产操作系统发展何如？
        纵观操作系统的发展史，可谓源远流长。
        早在20世纪40年代中期，便出现了世界上第一台真正的“电子计算机”，即电子数字计算机（electronic numerical integrator and computer，ENIAC）。此后，便逐步产生了对计算机操作系统的紧迫需求。
        在此背景下，各类操作系统不断涌现，其中较为成功的（早期）操作系统当属UNIX系统，其面向使用者提供了多任务、多层次的软件计算环境，并逐步发展成为主机时代的操作系统。UNIX系统由于较为成功且代码公开，在高校实验教学过程中应用较多。随后，在众多教育工作者和操作系统爱好者的努力下，由UNIX系统教学代码衍生出了UNIX系统的多个发行版本，如伯克利软件套件（Berkeley software distribution，BSD）等。

## 幻灯片 90

课程思政小讲堂

了解Windows应用初期，Linux问世，那现在国产操作系统发展何如？
	1991年10月5日，林纳斯·托瓦兹（Linux Torvalds）对外发布了其独立开发的类UNIX操作系统内核，当该内核与GNU计划（自由软件集体协作计划）相结合时，便形成了我们现在所熟知的开源（开放源代码）Linux系统。至此，Linux问世。
 	与Linux发展完全不同的另一个典型操作系统，便是由微软公司研发的Windows系统，其于1985问世之初仅是Microsoft-DOS模拟环境，之后经过不断完善系统体验、丰富图形用户界面，逐步变为目前全世界使用最广泛的计算机操作系统。
