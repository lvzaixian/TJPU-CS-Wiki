数据库原理：第三章关系数据库标准语言SQL测验

检验你对SQL数据定义、查询、更新及视图等核心概念的掌握程度！

一、单项选择题

1. SQL语言的特点不包括（　　）。

正确答案：C

解析：： SQL采用的是面向集合的操作方式，而不是面向记录的操作方式。层次、网状模型采用的是面向记录的操作方式。

2. 在SQL中，CREATE SCHEMA 语句的主要作用是（　　）。

正确答案：B

解析：： `CREATE SCHEMA` 用于定义一个模式（schema），它是一个命名空间，用于组织和管理数据库对象（如表、视图、索引）。

3. 执行 DROP SCHEMA Test RESTRICT; 语句时，如果模式Test中包含有表Tab1，则会发生什么？（　　）

正确答案：C

解析：： `RESTRICT` 选项表示“限制”，如果该模式中定义了任何数据库对象（如表、视图等），则拒绝该删除语句的执行，只有当模式为空时才能删除。而 `CASCADE` 选项才会级联删除模式中的所有对象。

4. 在SQL的 SELECT 语句中，用于消除查询结果中重复元组的关键字是（　　）。

正确答案：C

解析：： `DISTINCT` 关键字用于在查询结果中去除重复的行。`ALL` 是默认行为，表示保留所有重复行。

5. 关于SQL的 WHERE 子句和 HAVING 短语，下列说法正确的是（　　）。

正确答案：C

解析：： `WHERE` 子句作用于基本表或视图中的元组，用于筛选行，不能直接使用聚集函数。`HAVING` 短语作用于 `GROUP BY` 子句分组后的结果，用于筛选组，因此可以使用聚集函数。

6. 与普通连接不同，外连接操作的特点是（　　）。

正确答案：C

解析：： 普通连接（内连接）只会返回满足连接条件的元组。外连接（左外连接、右外连接、全外连接）会保留主体表中所有元组，即使它们在另一表中没有匹配的元组，未匹配的属性会用NULL填充。

7. SQL语言中，子查询的SELECT语句中不允许使用（　　）子句。

正确答案：C

解析：： 子查询的结果是一个关系，但其内部的SELECT语句通常不能包含 `ORDER BY` 子句，因为子查询的目的是返回数据集合供外层查询使用，其内部顺序无关紧G。实际系统可能会对某些简单子查询放宽此限制，但在标准概念上通常不允许。

8. 关于带有 EXISTS 谓词的子查询，下列说法正确的是（　　）。

正确答案：B

解析：： `EXISTS` 谓词只判断子查询的结果集是否为空。如果非空则返回 `TRUE`，否则返回 `FALSE`。因此，其目标列表达式通常用 `*`，因为它不返回实际数据。

9. 下列关于视图更新的描述中，哪一项是错误的？（　　）

正确答案：C

解析：： 并非所有视图都是可更新的。例如，包含聚集函数、`GROUP BY` 子句、`DISTINCT` 关键字、多表连接（某些情况）或导出属性的视图通常是不可更新的。

10. 判断一个属性的值是否为空值，应该使用的谓词是（　　）。

正确答案：B

解析：： 在SQL中，判断空值需要使用特殊的 `IS NULL` 或 `IS NOT NULL` 谓词，不能使用 `=` 或 `!=` 进行比较，因为空值不等于任何值，包括它自身。

11. 下列SQL动词中，属于数据控制功能的是（　　）。

正确答案：D

解析：： `GRANT` (授权) 和 `REVOKE` (撤销权限) 属于数据控制语言 (DCL)，用于管理数据库的安全性。

12. 在关系数据库管理系统中，一个关系通常对应一个（　　）。

正确答案：C

解析：： 在关系数据库管理系统中，关系模式的实例，即实际存储数据并独立存在的表，被称为基本表。

13. 修改表中某一列的数据类型应使用以下哪个语句？（　　）

正确答案：C

解析：： `ALTER TABLE ... ALTER COLUMN <列名> TYPE <数据类型>;` 是SQL标准中用于修改列数据类型的语法。

14. 数据库管理系统在执行SQL的数据定义语句（如 CREATE TABLE）时，会更新（　　）中的相应信息。

正确答案：B

解析：： 数据字典是RDBMS内部的系统表，存储了数据库中所有的数据定义信息（模式、表、视图、索引、完整性约束、用户权限等）。数据定义语句的执行就是对数据字典进行更新。

15. 当使用 INSERT INTO Student VALUES ('20180008', '张成民', '男','2000-4-15','计算机科学与技术'); 语句插入数据时，如果 Student 表的列顺序和类型与 `VALUES` 子句不匹配，会发生什么？（　　）

正确答案：C

解析：： 当 `INSERT` 语句没有指定列名时，`VALUES` 子句中的值的顺序和数据类型必须与表定义的列顺序和数据类型完全匹配。如果不匹配，数据库系统会报告错误并拒绝插入。

16. 在SQL中，使用 LIKE 谓词进行模式匹配时，表示任意长度字符串的通配符是（　　）。

正确答案：B

解析：： 在SQL的 `LIKE` 谓词中，`%` 表示任意长度（包括零长度）的字符串，`_` 表示任意单个字符。

17. 下列哪个SQL聚合函数不能用于数值类型以外的列？（　　）

正确答案：C

解析：： `SUM()` 函数用于计算数值列的总和，因此只能用于数值类型。`COUNT(*)` 计算行数，`MAX()` 和 `MIN()` 可以用于任何可排序的数据类型（数值、字符串、日期等），`AVG()` 也只能用于数值类型。

18. SQL语句的 FROM 子句主要用于（　　）。

正确答案：C

解析：： `FROM` 子句指定了查询操作所针对的关系，即从哪些基本表或视图中获取数据。

19. 向表中一次性插入多条元组，可以使用以下哪种方法？（　　）

正确答案：B

解析：： `INSERT INTO ... SELECT` 语句允许将一个查询的结果插入到另一个表中，是SQL中一次性插入多条元组的常用且高效的方法。A选项虽然可以插入多条，但需要执行多次语句。C和D是特定数据库系统的批量导入语句，不属于标准SQL。

20. 如果要删除一个表中的所有元组，但希望保留表结构和索引，以下哪种操作最合适？（　　）

正确答案：C

解析：： `TRUNCATE TABLE` 操作可以删除表中的所有行，同时保留表结构和索引，并且通常比 `DELETE FROM` 更快，因为它通常不记录单独的行删除日志。`DROP TABLE` 会删除表结构和数据。`DELETE FROM` 删除行但保留结构，但效率通常低于 `TRUNCATE`。

三、判断题

1. SQL语言对关键字和标识符的大小写不敏感。

正确答案：： 对

解析：： SQL是大小写不敏感的语言，这意味着 `SELECT`、`select` 和 `Select` 都是等效的。但是，某些数据库系统对于字符串常量或某些特定对象名可能会区分大小写。

2. 在SQL中，一个空值（NULL）与任何值进行比较（包括与另一个空值比较）的结果都是TRUE或FALSE。

正确答案：： 错

解析：： 空值与任何值（包括另一个空值）进行比较的结果都是 `UNKNOWN`（不确定），而不是TRUE或FALSE。因此，需要使用 `IS NULL` 或 `IS NOT NULL` 谓词来判断空值。

3. 视图是真实存储在数据库中的，因此对视图的任何操作都会直接修改其存储的数据。

正确答案：： 错

解析：： 视图是虚拟的表，它不存储真实的数据。对视图的操作会通过视图消解转换为对基本表的操作。而且，如前面选择题所述，并非所有视图都可更新。

4. `DROP TABLE` 语句用于删除整个数据库，包括所有表和数据。

正确答案：： 错

解析：：： `DROP TABLE` 只用于删除指定的表，而 `DROP DATABASE` 或 `DROP SCHEMA`（在某些系统中）才用于删除整个数据库或模式。

5. 在一个完整的 `SELECT` 语句中，`WHERE` 子句总是在 `GROUP BY` 子句之前执行。

正确答案：： 对

解析：：： SQL查询的逻辑处理顺序通常是：`FROM` -> `WHERE` -> `GROUP BY` -> `HAVING` -> `SELECT` -> `ORDER BY`。`WHERE` 子句用于筛选原始数据行，然后 `GROUP BY` 再对筛选后的行进行分组。

6. 外码（Foreign Key）不允许取空值（NULL）。

正确答案：： 错

解析：：： 外码是可以取空值的，这表示该元组与被参照表中的任何元组都没有关联。只有在定义外码时明确指定 `NOT NULL` 约束，它才不允许为空。

2. **假设存在 Department 表（DeptID 是主码）。请写出SQL语句，创建一个 Professor 表，包含 ProfID (主码), ProfName 和 DeptID。其中，DeptID 是外码，参照 Department 表的 DeptID。要求：当 Department 表中的部门被删除时，级联删除 Professor 表中对应的教授记录；当 Department 表中的 DeptID 被更新时，级联更新 Professor 表中对应的 DeptID。**

参考答案：


-- 假设 Department 表已存在
-- CREATE TABLE Department (DeptID CHAR(3) PRIMARY KEY, DeptName VARCHAR(50));

CREATE TABLE Professor (
    ProfID CHAR(4) PRIMARY KEY,
    ProfName VARCHAR(50) NOT NULL,
    DeptID CHAR(3),
    FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
        ON DELETE CASCADE -- 当部门被删除时，级联删除教授
        ON UPDATE CASCADE -- 当部门ID被更新时，级联更新教授的部门ID
);

解析：：

  1. 使用 `FOREIGN KEY (DeptID) REFERENCES Department(DeptID)` 定义外码关系。
  2. `ON DELETE CASCADE` 指定当父表 `Department` 的元组被删除时，子表 `Professor` 中所有引用该元组的记录也一并删除。
  3. `ON UPDATE CASCADE` 指定当父表 `Department` 的 `DeptID` 被更新时，子表 `Professor` 中所有引用该 `DeptID` 的记录的 `DeptID` 也一并更新。

3. **请写出SQL语句，创建一个 StudentScores 表，包含 StudentID (主码), CourseID 和 Score 字段。要求 Score 字段的值必须在 0 到 100 之间（包含0和100）。**

参考答案：


CREATE TABLE StudentScores (
    StudentID CHAR(8),
    CourseID CHAR(5),
    Score SMALLINT CHECK (Score >= 0 AND Score <= 100), -- 成绩范围约束
    PRIMARY KEY (StudentID, CourseID)
);

解析：：：

5. **请写出SQL语句，定义一个名为 CheckStudentMajor 的 BEFORE INSERT 行级触发器，作用于 Student 表。当插入新的学生记录时，如果学生的 Smajor 属性（专业）是 '计算机科学与技术'，并且学生的学号 Sno 以 '2' 开头，则将其 Smajor 自动改为 '软件工程'。**

参考答案：


CREATE TRIGGER CheckStudentMajor
BEFORE INSERT ON Student -- BEFORE INSERT 触发器，作用于Student表
REFERENCING NEW AS newTuple -- 定义newTuple来引用新插入的行数据
FOR EACH ROW -- 行级触发器
WHEN (newTuple.Smajor = '计算机科学与技术' AND newTuple.Sno LIKE '2%') -- 触发条件
BEGIN
    newTuple.Smajor := '软件工程'; -- 触发动作：修改Smajor为'软件工程'
END;

解析：：

  1. `CREATE TRIGGER CheckStudentMajor` 定义触发器名称。
  2. `BEFORE INSERT ON Student` 指定在 `Student` 表执行 `INSERT` 操作**之前**触发。
  3. `REFERENCING NEW AS newTuple` 允许在触发器中通过 `newTuple` 访问即将插入的新行的数据。
  4. `FOR EACH ROW` 指定这是一个行级触发器，对每一行受影响的数据都会执行一次。
  5. `WHEN (...)` 定义了触发条件：当新行的专业是'计算机科学与技术'且学号以'2'开头时。
  6. `BEGIN ... END;` 包裹触发动作体，其中 `newTuple.Smajor := '软件工程';` 会在实际插入前修改 `Smajor` 的值。

8. **请写出SQL语句，将同时借阅了 '数据库系统概论' (ISBN: B001) 和 '数据结构' (ISBN: B002) 两本书的读者的所有借阅记录的罚款金额提高10%。**

参考答案：


-- 将同时借阅了指定两本书的读者的罚款金额提高10%
UPDATE borrow
SET fine = fine * 1.1
WHERE rno IN (
    SELECT b1.rno
    FROM borrow b1
    JOIN borrow b2 ON b1.rno = b2.rno
    WHERE b1.bisbn = 'B001' AND b2.bisbn = 'B002'
);

解析：：

  1. `UPDATE borrow SET fine = fine * 1.1` 指定对 `borrow` 表进行更新，将 `fine` 字段值增加10%。
  2. `WHERE rno IN (...)` 子句用于筛选需要更新的记录，只更新那些同时借阅了两本书的读者的记录。
  3. 内部子查询通过自连接 `borrow` 表 (`b1` 和 `b2`) 来找到同时借阅了 `B001` 和 `B002` 的读者 `rno`。在这个例子中，只有 `R001` 同时借阅了这两本书。
  4. 因此，`R001` 的所有借阅记录的罚款金额都会提高10%。
