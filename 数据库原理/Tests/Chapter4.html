数据库原理：第四章数据库安全性测验

深入了解数据库安全的各种机制和挑战！

一、单项选择题

1. 数据库安全性是指保护数据库以防止不合法使用所造成的数据（　　）。

正确答案：A

解析： 数据库安全性主要关注数据的保密性、完整性和可用性，防止未经授权的泄露、篡改和破坏。

2. 关于自主存取控制（DAC）方法，下列说法正确的是（　　）。

正确答案：C

解析： DAC的特点是灵活，拥有权限的用户可以根据需要将权限转授给其他用户。A、B、D选项描述的是强制存取控制（MAC）的特点。

3. 强制存取控制（MAC）中，当主体试图读取客体时，必须满足的条件是（　　）。

正确答案：B

解析：： MAC的读操作规则是“只能上读，不能下写”。即主体的许可证级别必须大于或等于客体的密级才能读取，以防止高密级数据泄露给低密级用户。

4. 在 GRANT 语句中，添加 WITH GRANT OPTION 子句的含义是（　　）。

正确答案：B

解析：： `WITH GRANT OPTION` 允许被授权的用户将所获得的权限再转授给其他用户，实现权限的传播。

5. 执行 REVOKE SELECT ON TABLE Student FROM U1 CASCADE; 语句，如果用户U1曾将 `SELECT` 权限转授给了用户U2，则会发生什么？（　　）

正确答案：B

解析：： `CASCADE` 选项表示级联收回权限。当一个用户的权限被收回时，如果该用户曾将此权限转授给了其他用户，则这些被转授的权限也会被同时收回。

6. 通过视图机制，在数据库安全性方面可以实现的主要目标是（　　）。

正确答案：B

解析：： 视图可以作为安全机制，通过定义只包含部分行或列的子集，从而隐藏原始基本表中的敏感数据，只暴露用户有权查看的部分。

7. 数据库审计的主要作用是（　　）。

正确答案：B

解析：： 审计是指DBMS自动记录用户对数据库的各种操作，以便事后进行查询、分析和追溯。

8. 数据加密技术的主要目的是（　　）。

正确答案：C

解析：： 数据加密通过将明文转换为密文，有效地防止了数据在存储介质上或网络传输过程中被非法截获和解读，从而保证了数据的保密性。

9. 推断控制主要解决的问题是（　　）。

正确答案：B

解析：： 推断控制是为了防止用户通过对非敏感数据的合法访问，结合背景知识，推断出他们无权访问的敏感信息。

10. 数据库角色的主要作用是（　　）。

正确答案：C

解析：： 角色是权限的命名集合，可以一次性将多个权限授予一个角色，然后将这个角色授予多个用户，从而大大简化了权限管理。

二、填空题

1. 数据库管理系统的安全性控制模型通常包括事前控制、事中控制和。

正确答案： 事后控制

解析：： 事前控制通过身份鉴别和入侵检测，事中控制通过多层访问控制，事后控制通过审计。

2. 在强制存取控制（MAC）中，系统管理的全部实体分为和两大类。

正确答案： 主体，客体

解析：： 主体是活动实体（用户或进程），客体是被动实体（文件、表等）。

3. TCSEC/TDI安全评估准则的最高安全级别是级。

正确答案： A1

解析：： A1级代表“验证设计”，提供最高程度的安全保证。

4. 在某些数据库系统中，用于创建新用户并指定其创建数据库权限的SQL语句是 CREATE USER ... WITH 。

正确答案： CREATEDB

解析：： `CREATEDB` 是授予用户创建数据库权限的关键字。

5. 审计员通过查阅来监控数据库中的各种行为。

正确答案： 审计日志

解析：： 审计日志是记录所有数据库操作的地方，供审计员分析。

三、判断题

1. 数据库的安全性问题与计算机系统的安全性问题是相互独立的，彼此之间没有关联。

正确答案：错误

解析：： 数据库系统是计算机系统的一部分，其安全性与操作系统、网络等底层系统的安全性紧密相关。任何一个环节的漏洞都可能影响数据库的整体安全。

2. 在实现强制存取控制（MAC）的数据库系统中，通常会首先进行自主存取控制（DAC）检查，然后才进行MAC检查。

正确答案：正确

解析：： 大多数支持MAC的系统会首先通过DAC检查来过滤掉大部分不合法的操作，然后对通过DAC检查的数据对象再施加更严格的MAC检查。

3. 在定义视图时使用 WITH CHECK OPTION 子句，可以确保通过该视图进行的任何插入或修改操作都满足视图定义中的条件。

正确答案：正确

解析：： `WITH CHECK OPTION` 是视图的一个重要特性，它会阻止任何通过视图进行的更新操作（INSERT, UPDATE），如果这些操作会导致插入或更新的行不再满足视图的 `WHERE` 子句条件。

4. 为了确保数据库的绝对安全，审计功能应该始终保持开启状态，不应关闭。

正确答案：错误

解析：： 审计会消耗系统资源（时间和空间），因此DBA通常会根据应用的安全性要求，灵活地打开或关闭审计功能，或只对关键操作进行审计。

5. 在传输加密中，链路加密只加密报文，而端到端加密既加密报文也加密报头。

正确答案：错误

解析：： 实际情况是：链路加密加密报文和报头，而端到端加密只加密报文，不加密报头。因此，此说法是错误的。

四、SQL编程题

1. **请写出SQL语句，将 Student 表（假设已存在）的所有操作权限授予用户 Tom，并允许 Tom 将此权限再次授予其他用户。**

参考答案：

GRANT ALL PRIVILEGES
ON TABLE Student
TO Tom
WITH GRANT OPTION;

解析：

  1. `GRANT ALL PRIVILEGES`：授予所有权限。
  2. `ON TABLE Student`：指定操作对象是 `Student` 表。
  3. `TO Tom`：指定接收权限的用户是 `Tom`。
  4. `WITH GRANT OPTION`：允许 `Tom` 将获得的权限再授予其他用户。

2. **假设用户 Jerry 曾从 Tom 那里获得了对 Student 表的 SELECT 权限，而 Tom 最初的权限是从DBA那里获得了 WITH GRANT OPTION 的。现在请写出SQL语句，收回 Tom 对 Student 表的 SELECT 权限，并级联收回所有由 Tom 转授出去的相关权限。**

参考答案：

REVOKE SELECT
ON TABLE Student
FROM Tom CASCADE;

解析：

  1. `REVOKE SELECT`：收回 `SELECT` 权限。
  2. `ON TABLE Student`：指定操作对象是 `Student` 表。
  3. `FROM Tom`：指定被收回权限的用户是 `Tom`。
  4. `CASCADE`：确保所有由 `Tom` 级联转授出去的 `SELECT` 权限（包括 `Jerry` 的）也一并被收回。

3. **为了简化权限管理，请写出SQL语句：**

  • 创建名为 `CourseAdmin` 的角色。
  • 授予 `CourseAdmin` 角色对 `Course` 表（假设已存在）的 INSERT, UPDATE, DELETE 权限。

参考答案：

CREATE ROLE CourseAdmin;

GRANT INSERT, UPDATE, DELETE
ON TABLE Course
TO CourseAdmin;

解析：：

  1. `CREATE ROLE CourseAdmin;`：创建新的数据库角色 `CourseAdmin`。
  2. `GRANT INSERT, UPDATE, DELETE ON TABLE Course TO CourseAdmin;`：将指定的 `INSERT`, `UPDATE`, `DELETE` 权限授予刚创建的 `CourseAdmin` 角色。

4. **承接上题，请写出SQL语句，将 `CourseAdmin` 角色授予用户 Alice 和 Bob，并允许 Alice 将此角色继续授予其他人。**

参考答案：：

GRANT CourseAdmin
TO Alice, Bob
WITH ADMIN OPTION; -- WITH ADMIN OPTION 需谨慎使用，这里仅为示例

解析：

  1. `GRANT CourseAdmin`：授予 `CourseAdmin` 角色。
  2. `TO Alice, Bob`：指定接收角色的用户。
  3. `WITH ADMIN OPTION`：允许 `Alice` 和 `Bob` 进一步将 `CourseAdmin` 角色（及其权限）授予其他用户或角色。

5. **请写出SQL语句，收回用户 Bob 的 `CourseAdmin` 角色。**

参考答案：

REVOKE CourseAdmin
FROM Bob; -- 默认RESTRICT，如果Bob曾转授此角色，操作会失败。如需级联，加CASCADE。

解析：： `REVOKE <角色名> FROM <用户名>` 用于从指定用户回收角色。默认行为是 `RESTRICT`，意味着如果该角色曾被 `Bob` 转授出去，则需要使用 `CASCADE` 选项才能成功回收。
