第一部分：看程序写结果 (每题3分)

1.1

执行以下SQL代码后，请写出结果：

SELECT rname '姓名', 2014 - rage '出生年份'
FROM reader
WHERE rspecialty = '计算机科学';
答案：
姓名 出生年份
'张三'1994
'王五'1993
解析：

该查询从reader表中选择专业为'计算机科学'的读者，并计算他们的出生年份（假设当前年份为2014）。

1.2

执行以下SQL代码后，请写出结果：

SELECT DISTINCT rno '读者编号'
FROM borrow
WHERE fine > 0;
答案：
读者编号
'R001'
'R003'
解析：

该查询从borrow表中选择所有罚款金额大于0的借阅记录的读者编号，并去除重复值。

1.3

执行以下SQL代码后，请写出结果：

SELECT bpublisher, COUNT(bpublisher)
FROM book
GROUP BY bpublisher
HAVING COUNT(*) >= 2;
答案：
bpublisher Count(bpublisher)
'高等教育出版社'2
'清华大学出版社'1
'机械工业出版社'1
'电子工业出版社'1
'科学出版社'1
'工业出版社'1
'人民出版社'1
解析：

该查询按出版社对图书进行分组，并筛选出图书数量大于等于2的出版社及其图书数量。

1.4

执行以下SQL代码后，请写出结果：

SELECT rno, SUM(fine)
FROM borrow
GROUP BY rno
HAVING SUM(fine) > 5;
答案：
rno Sum(fine)
'R003'10.00
'R001'5.00
解析：

该查询按读者编号对借阅记录进行分组，并筛选出罚款总额大于5的读者编号及其罚款总额。

  • R001: 5.00 + 0.00 + 0.00 = 5.00 (不大于5) -> 不符合HAVING条件
  • R002: 0.00 (不大于5) -> 不符合HAVING条件
  • R003: 0.00 + 10.00 = 10.00 (大于5) -> 符合HAVING条件
  • R004: 0.00 (不大于5) -> 不符合HAVING条件
  • R005: 0.00 + 0.00 = 0.00 (不大于5) -> 不符合HAVING条件

1.8

执行以下SQL代码后，请写出结果：

SELECT DISTINCT rno
FROM borrow
WHERE fine > (
    SELECT AVG(fine)
    FROM borrow
    WHERE fine <> 0
);
答案：
rno
'R003'
解析：

该查询使用嵌套子查询。首先，计算所有非零罚款金额的平均值：(5.00 + 10.00) / 2 = 7.50。然后，选择罚款金额大于7.50的读者的编号，并去除重复值。

    FROM borrow
    WHERE rno = reader.rno
    AND bisbn = 'B001'

答案：
rno rname
'R001''张三'
'R002''李四'
'R004''赵六'

该查询使用EXISTS子查询。对于reader表中的每一行，它检查是否存在相应的borrow记录，使得该读者借阅了ISBN为'B001'的图书。如果存在，则返回该读者的编号和姓名。

第二部分：编程题 (每题5分)

2.1

请编写SQL语句，使用集合查询，查询借阅 ISBN 号为 'B001' 或 'B002' 图书的读者编号。

参考答案： 

SELECT rno FROM borrow WHERE bisbn = 'B001'
UNION
SELECT rno FROM borrow WHERE bisbn = 'B002';
解析：

该题考察UNION集合操作符，它用于合并两个或多个SELECT语句的结果集，并自动去除重复的行，从而得到借阅了任一指定图书的读者编号。

2.2

请编写SQL语句，使用集合查询，查询所有读者中，从未借阅过 ISBN 号为 'B006' 图书的读者编号。

参考答案： 

SELECT rno FROM reader
EXCEPT
SELECT rno FROM borrow WHERE bisbn = 'B006';
解析：

该题考察EXCEPT（或MINUS，取决于数据库系统）集合操作符。它用于返回第一个SELECT语句的结果中，减去第二个SELECT语句结果后剩余的行，从而得到从未借阅过指定图书的读者编号。

2.3

请编写SQL语句，使用嵌套查询，查询比'李四'年龄小的读者姓名。

参考答案： 

SELECT rname FROM reader
WHERE rage < (SELECT rage FROM reader WHERE rname = '李四');
解析：

该题考察嵌套查询。内层查询首先找出'李四'的年龄，外层查询再选择所有年龄小于这个值的读者姓名。

2.4

请编写SQL语句，使用嵌套查询，查询其他专业中比'计算机科学'专业所有读者年龄都大的读者姓名和年龄。

参考答案： 

SELECT rname, rage FROM reader
WHERE rspecialty <> '计算机科学'
AND rage > ALL (SELECT rage FROM reader WHERE rspecialty = '计算机科学');
解析：

该题考察带有ALL操作符的嵌套查询。内层查询找出'计算机科学'专业所有读者的年龄，外层查询则选择其他专业中年龄大于这些所有年龄的读者。

2.5

假设已存在一个名为 borrow_count 的新表，结构如下：

rno (char(5)) amount (int)
主码

请编写SQL语句，汇总每位读者的借书总数，并插入到 borrow_count 表中。

参考答案： 

INSERT INTO borrow_count(rno, amount)
SELECT rno, COUNT(*)
FROM borrow
GROUP BY rno;
解析：

该题目考察使用INSERT INTO ... SELECT语句和GROUP BY进行数据汇总和插入。GROUP BY rno将借阅表按读者编号分组，COUNT(*)计算每个组（即每个读者）的借书总数。然后将这些汇总结果插入到borrow_count表中。

2.6

假设已存在一个名为 reader_fee 的新表，结构如下：

rno (char(5)) fee (numeric(7,2))
主码

请编写SQL语句，汇总每位读者的罚款总额，并插入到 reader_fee 表中。

参考答案： 

INSERT INTO reader_fee(rno, fee)
SELECT rno, SUM(fine)
FROM borrow
GROUP BY rno;
解析：

该题目考察使用INSERT INTO ... SELECT语句和GROUP BY进行数据汇总和插入。GROUP BY rno将借阅表按读者编号分组，SUM(fine)计算每个组（即每个读者）的罚款总额。然后将这些汇总结果插入到reader_fee表中。

2.7

请编写SQL语句，删除读者姓名是'张三'（假设无重名）的所有借阅记录。

参考答案： 

DELETE FROM borrow
WHERE rno = (SELECT rno FROM reader WHERE rname = '张三');
解析：

该题目考察使用子查询进行删除操作。首先，子查询(SELECT rno FROM reader WHERE rname = '张三')会找到名为'张三'的读者的编号。然后，DELETE语句将删除borrow表中所有匹配该读者编号的借阅记录。

2.8

请编写SQL语句，删除图书名称是'数据结构'（假设无重名）的所有借阅记录。

参考答案： 

DELETE FROM borrow
WHERE bisbn = (SELECT bisbn FROM book WHERE bname = '数据结构');
解析：

该题目考察使用子查询进行删除操作。首先，子查询(SELECT bisbn FROM book WHERE bname = '数据结构')会找到名为'数据结构'的图书的ISBN号。然后，DELETE语句将删除borrow表中所有匹配该ISBN号的借阅记录。

2.9

请编写SQL语句，使用连接查询或子查询，将同时借阅 ISBN 号为 'B001' 和 'B002' 这两本书的读者的所有借阅记录的罚款金额 fine 改为 0。

参考答案： 

UPDATE borrow
SET fine = 0
WHERE rno IN
(
    SELECT B1.rno
    FROM borrow B1, borrow B2
    WHERE B1.rno = B2.rno
    AND B1.bisbn = 'B001'
    AND B2.bisbn = 'B002'
);
解析：

该题目考察使用子查询进行复杂更新。首先，通过子查询（自连接borrow表）找出同时借阅了'B001'和'B002'两本书的读者编号集合。然后，使用UPDATE语句，结合WHERE ... IN子句，将这些读者对应的所有借阅记录的罚款金额设置为0。

2.10

请编写SQL语句，使用连接查询或子查询，将同时借阅 ISBN 号为 'B001' 和 'B002' 这两本书的读者的所有借阅记录的罚款金额提高 10%。

参考答案： 

UPDATE borrow
SET fine = fine * 1.1
WHERE rno IN
(
    SELECT B1.rno
    FROM borrow B1, borrow B2
    WHERE B1.rno = B2.rno
    AND B1.bisbn = 'B001'
    AND B2.bisbn = 'B002'
);
解析：

该题目考察使用子查询进行复杂更新。首先，通过子查询（自连接borrow表）找出同时借阅了'B001'和'B002'两本书的读者编号集合。然后，使用UPDATE语句，结合WHERE ... IN子句，将这些读者对应的所有借阅记录的罚款金额增加10%。
