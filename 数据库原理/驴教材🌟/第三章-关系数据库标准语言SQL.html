3.1 SQL概述 必考

核心概念与特点

SQL (Structured Query Language)，结构化查询语言，是关系数据库的标准语言。它集数据查询、数据操纵、数据定义和数据控制功能于一体。

SQL的主要特点包括：

  • 综合统一： 具备数据定义、数据操纵、数据控制等多种功能。
  • 高度非过程化： 用户只需提出“做什么”的逻辑需求，而无需指定“怎么做”的具体实现步骤，由数据库管理系统自动优化执行。
  • 面向集合的操作方式： 操作对象和返回结果都是元组的集合。
  • 语言简洁，易学易用： 功能强大，核心操作仅需少数几个动词（如 `CREATE`, `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `GRANT`, `REVOKE`）。

SQL语法模板与关键词总结

SQL基本语法结构

SELECT [DISTINCT] <列名> | <表达式> | <聚合函数>
FROM <表名> | <视图名>
[WHERE <条件表达式>]
[GROUP BY <分组列>]
[HAVING <分组条件>]
[ORDER BY <排序列> [ASC | DESC]]
[LIMIT <行数>];

SQL语句以动词开头，后跟子句，大多数语句以分号结束。

SQL的产生与发展 (了解)

SQL由美国IBM公司的E.F.Codd于1970年提出关系数据模型后，逐步发展成为关系数据库的标准语言。随着时间的推移，SQL标准不断演进，例如SQL 92、SQL 99、SQL 2003、SQL 2016等版本，引入了XML类型、窗口函数、JSON类型等新特性。然而，需要注意的是，目前没有一个关系数据库管理系统能够完全支持SQL标准的所有概念和特性。

3.2 数据定义 重要

创建数据库与表

数据定义语言 (DDL) 主要用于创建、修改和删除数据库对象，如表、视图、索引等。

创建数据库

用于创建一个新的数据库实例。

SQL Code
CREATE DATABASE SchoolDB;

执行结果： 数据库 SchoolDB 创建成功。

创建表

定义基本表的结构，包括列名、数据类型、完整性约束等。

SQL Code
-- 创建学生表 (Student) CREATE TABLE Student (     Sno CHAR(9) PRIMARY KEY, -- 学号，主码     Sname VARCHAR(20) NOT NULL UNIQUE, -- 姓名，非空且唯一     Ssex CHAR(2), -- 性别     Sbirthdate DATE, -- 出生日期     Smajor VARCHAR(20) -- 专业 );

执行结果： 表 Student 创建成功。

SQL Code
-- 创建课程表 (Course) CREATE TABLE Course (     Cno CHAR(4) PRIMARY KEY, -- 课程号，主码     Cname VARCHAR(20) NOT NULL, -- 课程名     Cpno CHAR(4), -- 先行课号     Ccredit SMALLINT, -- 学分     FOREIGN KEY (Cpno) REFERENCES Course(Cno) -- 外码约束 );

执行结果： 表 Course 创建成功。

SQL Code
-- 创建学生选课表 (SC) CREATE TABLE SC (     Sno CHAR(9), -- 学号     Cno CHAR(4), -- 课程号     Grade SMALLINT, -- 成绩     PRIMARY KEY (Sno, Cno), -- 复合主码     FOREIGN KEY (Sno) REFERENCES Student(Sno) -- 外码约束         ON DELETE CASCADE, -- 删除学生时，级联删除选课记录     FOREIGN KEY (Cno) REFERENCES Course(Cno) -- 外码约束         ON DELETE NO ACTION -- 删除课程时，禁止操作（或 SET NULL, SET DEFAULT） );

执行结果： 表 SC 创建成功。

SQL约束类型与用法

约束类型 关键词 描述 示例
主键约束 PRIMARY KEY 唯一标识表中的每条记录 Sno CHAR(9) PRIMARY KEY

3.5 空值的处理 了解

空值的概念与判断

空值 (NULL) 表示“不知道”、“不存在”或“无意义”的值。它不同于零或空字符串。SQL中对空值的处理有特殊规则，例如任何涉及空值的算术、比较或逻辑运算，结果通常也是空值（UNKNOWN）。判断空值必须使用 IS NULL 或 IS NOT NULL，不能使用 = NULL 或 != NULL。

判断空值

查询所有没有先行课的课程信息 (即 Cpno 为空值)。

-- 查询所有没有先行课的课程 SELECT * FROM Course WHERE Cpno IS NULL;

3.6 视图 重要

创建视图 (CREATE VIEW)

视图是从一个或多个基本表（或视图）导出的虚表。它不存储实际数据，只存储定义视图的查询语句。

创建学生选课视图

创建一个视图，显示学生的学号、姓名、课程名称和成绩。

SQL Code
-- 创建一个视图，显示学生的学号、姓名、课程名称和成绩 CREATE VIEW StudentCourseView (Sno, Sname, Cname, Grade) AS SELECT S.Sno, S.Sname, C.Cname, SC.Grade FROM Student S, SC, Course C WHERE S.Sno = SC.Sno AND SC.Cno = C.Cno;

执行结果： 视图 StudentCourseView 创建成功。

查询视图

通过视图 StudentCourseView 查询所有课程成绩在90分以上的学生信息。

SQL Code
-- 通过视图查询成绩在90分以上的学生信息 SELECT * FROM StudentCourseView WHERE Grade >= 90;
