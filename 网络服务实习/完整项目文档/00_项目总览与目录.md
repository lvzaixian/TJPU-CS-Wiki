# 网络服务与安全实习 - 完整项目文档

## 项目概述

本项目采用 **Unraid (基于 KVM)** 虚拟化平台，模拟中小型企业网络环境，实现以下核心功能：

- **虚拟化平台**：Unraid + VLAN 逻辑隔离
- **网络架构**：OpenWRT（边界路由）+ iKuai（核心防火墙）纵深防御
- **域服务**：Windows Server 2019 Core 提供 AD DS + DNS
- **文件服务**：Server1 (Ubuntu) 提供 FTP/SMB/NFS，支持域用户三级权限
- **Web 服务**：Server2 (Ubuntu) + Nginx，通过 NFS 挂载实现存算分离
- **VPN 服务**：OpenWRT WireGuard，支持外网用户安全接入内网
