# 内容一：虚拟化平台配置

## 1. 平台选型

本项目采用 **Unraid** 作为虚拟化平台，其底层基于 **Linux KVM** 虚拟化技术。

### 选型理由

- Unraid 提供成熟的 KVM 虚拟机管理界面
- 支持 VLAN 网络隔离，可在单网卡上模拟多网段
- 若 CPU 性能不足，可导出 KVM XML 配置迁移到其他 Ubuntu Server 上运行

---

## 2. VLAN 网络配置

由于宿主机只有单网卡，需要通过 VLAN 技术实现网络隔离。在 Unraid 的 `br0` 网桥上创建三个 VLAN 接口，分别对应拓扑中的三个二层交换机：

| VLAN ID | 网段 | 用途 |
|---------|------|------|
| VLAN 100 | 192.168.13.0/24 | 中转区（R1 ↔ FW） |
| VLAN 200 | 192.168.14.0/24 | 客户端区 |
| VLAN 300 | 192.168.1.0/24 | 服务器区 |

### 使用说明

组员下载对应的 WireGuard 配置文件后，即可：
1. 连接到 Unraid 管理界面
2. 通过 SSH 连接到各虚拟机
3. 访问虚拟机的 Web 管理界面（如 OpenWRT、iKuai）

## 4. 虚拟机资源分配

| 虚拟机 | vCPU | 内存 | 磁盘 | 网卡 |
|--------|------|------|------|------|
| R1 (OpenWRT) | 1 | 512MB | 512MB | virbr0, br0.100, br0.200 |
| FW (iKuai) | 1 | 1GB | 2GB | virbr0, br0.100, br0.300 |
| Server1 | 2 | 2GB | 20GB | virbr0, br0.300 |
| Server2 | 2 | 2GB | 20GB | virbr0, br0.300 |
| Server3 | 2 | 4GB | 40GB | virbr0, br0.300 |
| Client1 | 2 | 2GB | 20GB | br0.200 |
| Client2 | 2 | 2GB | 20GB | br0.200 |
| Client3 | 2 | 4GB | 80GB | br0.200 |

> **说明**：virbr0 是 Unraid 宿主机的 NAT 网络，用于临时 SSH 管理连接，不参与业务流量。
