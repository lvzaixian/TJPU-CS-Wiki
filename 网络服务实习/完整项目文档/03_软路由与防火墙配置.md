### 2. 基础网络配置

#### 2.1 配置 WAN 口静态 IP

先手动为 WAN 口指定静态 IP 地址，以便通过它访问 Web 界面：

```bash
uci set network.wan.proto='static'
uci set network.wan.ipaddr='192.168.122.100'
uci set network.wan.netmask='255.255.255.0'
uci set network.wan.gateway='192.168.122.1'
uci commit network
/etc/init.d/network restart
```

![WAN 配置](assets/image-20260109100426-n9347hj.png)

#### 2.2 放通 Web 管理端口

默认 WAN 口不能访问 Web 管理界面，需要手动放通 80 端口：

```bash
uci add firewall rule
uci set firewall.@rule[-1].name='Allow-OpenWrt-Web-80'
uci set firewall.@rule[-1].src='wan'
uci set firewall.@rule[-1].proto='tcp'
uci set firewall.@rule[-1].dest_port='80'
uci set firewall.@rule[-1].target='ACCEPT'
```

![防火墙规则](assets/image-20260109222509-4t0r2is.png)

通过 `http://192.168.122.100` 即可访问 Web 界面：

![OpenWRT Web 界面](assets/image-20260109100440-ewwbl85.png)

| Server1 | (从 Unraid 获取) | 192.168.1.100 | 192.168.1.102 |
| Server2 | (从 Unraid 获取) | 192.168.1.101 | 192.168.1.102 |
| Server3 | (从 Unraid 获取) | 192.168.1.102 | 无 (自身是 DNS) |
