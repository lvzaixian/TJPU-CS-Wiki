### 2. Server1 基础配置

#### 2.1 配置 root 密码

为 root 分配密码方便之后管理：

```bash
sudo passwd root
```

![root 密码](assets/image-20260109200304-uwltvuj.png)

#### 2.5 解决双网卡路由冲突

由于 Server 有双网卡，每个网卡在获取 DHCP 时都声明了优先级相同的默认网关并向路由表注入默认路由，导致路由冲突。

需要在 `netplan` 配置中明确指定前往各个子网要走 `192.168.1.1`，并修改两个网卡的优先级：

```yaml
# /etc/netplan/00-installer-config.yaml
network:
  version: 2
  ethernets:
    enp1s0:  # NAT 网卡
      dhcp4: true
      dhcp4-overrides:
        route-metric: 200
    enp2s0:  # 业务网卡
      dhcp4: true
      dhcp4-overrides:
        route-metric: 100
      routes:
        - to: 192.168.13.0/24
          via: 192.168.1.1
        - to: 192.168.14.0/24
          via: 192.168.1.1
        - to: 10.13.13.0/24
          via: 192.168.1.1
```

## 二、Windows Server 2019 Core 部署 (Server3)

### 1. 配置 SSH 远程管理

为了避免一直在 VNC 中工作，为服务器配置 SSH：

```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
```

#### 1.1 配置 SSH 允许密码登录

编辑配置文件：

```powershell
notepad C:\ProgramData\ssh\sshd_config
```

![SSH 配置1](assets/image-20260108182140-8uhsp38.png)

![SSH 配置2](assets/image-20260108182158-o16oxr0.png)

#### 1.2 启动 SSH 服务

```powershell
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'
```

即可在 SSH 客户端连接：

```bash
ssh administrator@192.168.122.82
```

![SSH 连接](assets/image-20260108182248-yjbvcpm.png)
