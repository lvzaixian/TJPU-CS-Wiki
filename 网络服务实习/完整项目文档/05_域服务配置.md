# 内容三(3)：域服务配置

## 一、安装 AD DS 与 DNS (Server3)

### 1. 安装域服务

在 Server3 上通过 PowerShell 安装 AD 域服务：

```powershell
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
```

### 2. 创建新林

创建域 `home.lab`：

```powershell
$MyDomainName = "home.lab"

Install-ADDSForest `
    -DomainName $MyDomainName `
    -DomainNetbiosName "CORP" `
    -InstallDns:$true `
    -NoRebootOnCompletion:$false `
    -Force:$true
```

![安装域服务](assets/image-20260108182602-5jjkojo.png)

> **说明**：安装新林过程完成后，服务器强制重启。等待设置过程完成后再重新通过 SSH 登录。

## 二、DNS 记录配置

### 1. 添加服务器 A 记录

我们希望服务器可以通过主机名对应的域名访问，需要手动向域注册 A 记录：

```powershell
Add-DnsServerResourceRecordA -Name "server1" -ZoneName "home.lab" -IPv4Address "192.168.1.100"
Add-DnsServerResourceRecordA -Name "server2" -ZoneName "home.lab" -IPv4Address "192.168.1.101"
```

### 2. 验证 DNS 记录

用 `Get-DnsServerResourceRecord` 验证结果：

```powershell
Get-DnsServerResourceRecord -ZoneName "home.lab"
```

![DNS 记录](assets/image-20260108200230-2h31fp6.png)

### 3. 清理多余的 A 记录

由于 Server3 有两张网卡，域控制器会自动将临时管理网卡的 IP 也注册到 A 记录下：

```powershell
Get-DnsServerResourceRecord -ZoneName "home.lab" -Name "server3"
```

![多余记录](assets/image-20260108200416-fb1l1yj.png)

查看网卡名称：

```powershell
ipconfig
```

![查看网卡](assets/image-20260108200557-ixuf7xw.png)

禁止该网卡自动注册，并清理旧记录：

```powershell
Set-DnsClient -InterfaceAlias "以太网" -RegisterThisConnectionsAddress $False
Remove-DnsServerResourceRecord -ZoneName "home.lab" -Name "server3" -RRType "A" -RecordData "192.168.122.82" -Force
```

验证结果：

![清理后验证](assets/image-20260108200825-d3nhp37.png)

## 三、创建域用户和组

### 1. 创建安全组

根据实验要求，创建三个安全组：

```powershell
# 创建组织单元
New-ADOrganizationalUnit -Name "实验用户" -Path "DC=home,DC=lab"

# 创建安全组
New-ADGroup -Name "admins" -GroupScope Global -GroupCategory Security -Path "OU=实验用户,DC=home,DC=lab"
New-ADGroup -Name "teachers" -GroupScope Global -GroupCategory Security -Path "OU=实验用户,DC=home,DC=lab"
New-ADGroup -Name "students" -GroupScope Global -GroupCategory Security -Path "OU=实验用户,DC=home,DC=lab"
```

### 2. 创建域用户

为每个组创建至少 2 个用户：

```powershell
# 设置通用密码
$Password = ConvertTo-SecureString "Admin123456" -AsPlainText -Force

# 创建管理员组用户
New-ADUser -Name "admin01" -SamAccountName "admin01" -UserPrincipalName "admin01@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true
New-ADUser -Name "admin02" -SamAccountName "admin02" -UserPrincipalName "admin02@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true

# 创建教师组用户
New-ADUser -Name "teacher01" -SamAccountName "teacher01" -UserPrincipalName "teacher01@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true
New-ADUser -Name "teacher02" -SamAccountName "teacher02" -UserPrincipalName "teacher02@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true

# 创建学生组用户
New-ADUser -Name "stu01" -SamAccountName "stu01" -UserPrincipalName "stu01@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true
New-ADUser -Name "stu02" -SamAccountName "stu02" -UserPrincipalName "stu02@home.lab" -Path "OU=实验用户,DC=home,DC=lab" -AccountPassword $Password -Enabled $true -PasswordNeverExpires $true

# 将用户加入对应组
Add-ADGroupMember -Identity "admins" -Members "admin01","admin02"
Add-ADGroupMember -Identity "teachers" -Members "teacher01","teacher02"
Add-ADGroupMember -Identity "students" -Members "stu01","stu02"
```
