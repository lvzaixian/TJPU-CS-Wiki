### 2. 连接到域

#### 2.1 验证 DNS 解析

由于 R1 LAN2 上正确的 DHCP 配置，已经可以解析到域：

![DNS 解析](assets/image-20260109211215-lqvo0cg.png)

#### 2.2 安装必要的包

```bash
sudo apt install -y realmd sssd sssd-tools adcli krb5-user packagekit samba-common-bin
```

![安装包1](assets/image-20260109211413-3ua446x.png)

![安装包2](assets/image-20260109211529-pc4mmb1.png)

#### 2.3 发现并加入域

```bash
realm discover home.lab
sudo realm join home.lab -U Administrator
```

![发现域](assets/image-20260109211630-z9nvkhm.png)

![加入域](assets/image-20260109211639-7yrbacm.png)

验证加入状态：

```bash
realm list
```

![验证加入](assets/image-20260109211658-lwqve9o.png)

#### 2.4 配置域用户自动创建家目录

执行 `sudo pam-auth-update`，勾选为域用户创建家目录：

![PAM 配置](assets/image-20260109211832-fhxu3vx.png)

#### 2.5 以域用户身份登录

重启并以域用户身份登录：

![登录界面](assets/image-20260109212244-rd7kr58.png)

![域用户登录](assets/image-20260109212017-ynnvdm2.png)

![登录成功](assets/image-20260109213726-cn9uiyx.png)

> **说明**：Client1 按相同方法操作即可。
