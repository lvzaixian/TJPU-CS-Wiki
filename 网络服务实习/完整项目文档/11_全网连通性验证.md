## 七、路由路径分析

### 客户端访问服务器的路由路径

```
Client3 (192.168.14.100)
    │
    │ 默认网关
    ▼
R1 LAN2 (192.168.14.1)
    │
    │ 静态路由: 192.168.1.0/24 via 192.168.13.150
    ▼
R1 LAN1 (192.168.13.1)
    │
    ▼
FW WAN (192.168.13.150)
    │
    │ ACL 检查
    ▼
FW LAN (192.168.1.1)
    │
    ▼
Server1/2/3 (192.168.1.x)
```

### VPN 用户访问内网的路由路径

```
VPN Client (公网)
    │
    │ WireGuard 隧道 (UDP 51820)
    ▼
R1 WAN (192.168.122.100)
    │
    │ VPN 接口路由
    ▼
R1 VPN (10.13.13.1)
    │
    │ 路由到内网网段
    ▼
R1 LAN1 → FW → 服务器区
    或
R1 LAN2 → 客户端区
```
