## 第 40 页

二、RISC 的主要特征 
Ø  选用使用频度较高的一些 简单指令，
      复杂指令的功能由简单指令来组合
Ø   指令 长度固定、指令格式种类少、寻址方式少
Ø   只有 LOAD / STORE 指令访存
Ø   采用 流水技术  一个时钟周期 内完成一条指令
Ø   采用 组合逻辑 实现控制器 Ø   CPU 中有多个 通用 寄存器 
Ø   采用 优化 的 编译 程序

## 第 41 页

三、CISC 的主要特征 
Ø  系统指令 复杂庞大，各种指令使用频度相差大
Ø   指令 长度不固定、指令格式种类多、寻址方式多
Ø   访存 指令 不受限制
Ø   大多数指令需要 多个时钟周期 执行完毕
Ø   采用 微程序 控制器 Ø   CPU 中设有 专用寄存器 
Ø   难以 用 优化编译 生成高效的目的代码

2. RISC 更能 提高计算机运算速度
